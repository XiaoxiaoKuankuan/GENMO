# 2026-10-31：物理执行Loss平台原因诊断

本次为不停正式八卡训练的只读CPU诊断，不更新GENMO、SM、WM、normalizer或优化器，
不启动Newton、不调整lambda、不改变参考或Loss定义。正式运行加载源码3e2b57d；
本次核对trainer/actor/reference/execution/losses与该版本无差异。

## 已核验的统计和执行链

- 物理更新每4步一次；每rank4个窗口，8rank共32。各rank物理Loss之和乘8/全局有效数，
  再由DDP平均，等价于全局有效窗口均值，没有额外除8或除256的问题。
- 日志的execution_loss汇总区间内各rank执行Loss之和，除以同区间全局有效窗口数；
  数据和Future Loss按普通更新数平均。后者包含没有Future更新的步，不能直接与仅一次
  Future前向的Loss比较。每步显示的x0梯度可能为零，要看区间最大值和累计更新数。
- 全部执行窗口仍逐控制步重新计算SM动作、递归推进WM，未发现detach或GT替换切断学生图。
  实测网络参数梯度包括Transformer、音乐/历史/前缀及FutureEncoder。
- 固定样本中原已提交参考和GT经过codec解码后的参考执行Loss最大差2.98e-8；
  没有观察到codec、固定anchor、关节映射或参考合并造成的额外基线误差。

四个数据来源各预先随机选4首，每首按现有合法请求表选一个运动类型和时刻；
使用同一请求、真实起点、history、FutureContext、epsilon，以及k=50/100/250。
这里四来源等权，不能把这批均值当成正式按source抽样的全库平均值。
每个checkpoint有48个学生执行窗口，共144个，全部完整H32，无拒绝。

当前总Loss掺入这部分原有跟踪误差后，对学生新增误差的变化显得不敏感。
可在监控中补充同窗口基线与差值；从Loss中减去detach基线不会改变梯度，不能当成优化修复。

## H32的实际时间覆盖

固定窗口均有11个preview-only控制步和21个中心消费步。前11步仍能通过未来goal/速度halo
影响SM，不是无梯度。每窗实际依赖19～20个新30Hz源点，只覆盖未知段的41.3%～51.4%。
物理图完整32步并不等于60帧生成轨迹全部接受执行优化。该设计限制了单次更新能修正的
范围，但没有发现把全部新参考挡在窗口外的接管错误。

物理噪声实际为50/100/250，普通监督仍覆盖0..999。前者是有同源动作信息的去噪任务，
不能把它的Loss水平与完整噪声监督或纯噪声生成混为一谈。

## 参数梯度测量与边界

先用32个数据样本与4个物理窗口作小批检查：乘lambda=0.02后的执行梯度范数约为数据
梯度的0.344%，全参数夹角余弦0.0086。这不是正式8卡全局比值。
因此另用85k完整断点的8rank独立采样器状态，在CPU顺序计算每rank原256数据样本、
4个Future样本、4个物理窗口，并进行全局平均；不拆分普通batch，保留mask和topk等
损失归约。CPU dropout使用固定新种子，CPU BF16不声称逐位复现CUDA执行。
该实测已完成，用时287.29秒，2048个普通监督样本、32个Future样本、32个完整H32窗口。
抽样来源为AIOZ28、AIST++2、FineDance1、Mine1，共32个不同source，无拒绝。

## 原因、未证实事项和处理建议

1. 已证实：总执行Loss包含较大的已有真实跟踪误差，固定样本上的学生超基线误差其实
   在下降；原滚动指标没有同步基线/分项，加上每步更换样本，掩盖了这部分进步。
2. 已测到：正式批量规模下物理梯度加权后仅约监督梯度0.64%，且每4步一次；它是较弱
   的正则约束，不能仅凭lambda=0.02或更新次数推断它主导了物理改进。
3. 时间范围限制：H32的可微影响覆盖有限的新参考源点，已发生的状态误差与保护前缀
   保持不变；该短窗不能代表全部60帧或整首歌的反事实优化。
4. 未发现：DDP额外缩小8倍、参考解码/anchor基线错位、执行链断图、全部更新被门禁
   阻塞等实现故障。本次结论不需要修改WM权重。

应补充固定请求的分项、真实/GT参考基线与学生差值、网络参数梯度比例及消费覆盖监控。
从展示值减去常数基线只改善可读性，不改善优化梯度；不应改成学生自己生成的参考作
目标，或逐步重对齐消除误差。若随后调整物理权重/频率，应根据参数梯度和真实执行效果
判断，而非把总Loss强压到零。本次没有改正式训练权重/频率，也没有自动启动新的方法对照。

没有重新做Newton方向测试，因此仍不能据本次诊断声明真实学生物理梯度方向、自由生成
或完整歌曲执行质量已经改善。固定样本改善也不能单独归因于物理项，数据监督同时在学习。

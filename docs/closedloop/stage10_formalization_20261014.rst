已实施的算法和数据流
--------------------

* B3 使用 Stage1 的独立冻结 Actor 副本生成前16步，后4步使用可训练 Actor。
  两套条件编码各自缓存；可训练条件不 detach，不跨 optimizer 更新使用旧图。
  BC 更新可训练 Actor，不能修改冻结副本。行为仍完整20步，最终 KL 仍检查
  全部20步；冻结部分坐标 KL 超过1e-12直接拒绝。
* 末4步训练目标按链数与4步归一化。保留自由有效坐标平均 log-ratio 代理、
  原始联合概率和真实 joint KL；前缀、padding 与因果参考保护保持原合同。
  本候选采用末4步，替代主配置此前的随机 K8；Full20/K8 作为明确对照能力保留。
* B4 的0.12具体是20步下限 ``[0.001]*16+[0.08,0.10,0.12,0.12]``，
  eta=0.1、CFG=2.5。两组使用相同噪声、行为身份和本机重新测量的部署合同。
* B2 每1000万实际训练控制步，在当前固定 Actor 下重新采集完整 MC 验证。
  EV低于0.9时另采当前策略训练银行并比较原有MC/TD混合候选。接受与拒绝后
  实际 Critic 指标分别记录；拒绝后恢复的模型不能用被拒候选的指标冒充。
  不复用 Stage1 旧 MC 标签作为更新后策略的无偏价值标签。
* Critic 保持 Stage1 条件编码器的独立冻结副本，以及256维、2层、4头时序
  Transformer和 Value Head。没有解冻编码器、另换网络或叠加新奖励损失。
* Stage2 音乐奖励关闭；音乐条件、CFG和 Stage1 BC 音乐动作监督继续生效。
  tracking 仍含配对动作活动度门控，报告实际活动度与参考边界，不把音乐项
  关闭解释为音乐条件关闭。
* 物理 episode 跨4秒共享世界采集窗口持续；正常环境保留音乐、状态历史和
  已承诺参考。优化期间物理暂停。歌曲结束或真实失败终止，独立行政截断单列。
  实际生成60帧，保持30Hz、0.5秒重规划、GMT50Hz和四个200Hz物理子步。

效率改进及实测边界
------------------

E0 补充请求摘要、拷贝、反馈、证据构建、reward和持久化等计时。完整/日常
各3个连续窗口、8个rank的顶层不重叠计时残差为0.763至1.152秒，48份检查
均小于3秒。嵌套 CUDA/host 计时不能重复相加，也不能把 CUDA event 区间
直接称为纯矩阵核忙碌率。

E1 将MC校准和严格诊断周期均设为1000万真实训练控制步，使用ndarray.v2
证据格式。评估每150万步；实际转移数可变，调度不按固定轮数猜测。

E2 使用每卡一个常驻4环境评估世界。各slot独立reset/retire，长歌曲分配到
不同rank，同曲所有种子固定在同rank；每行随机数独立，不依赖批量排列。
训练世界在评估期间暂停，不并行推进两套物理采集。checkpoint先取得不可变
CPU快照，再单个在途任务异步写入；实际权重落盘后才发布best指针。

Critic预热与完整歌曲基线
-----------------------

最初16首训练歌的新N4预热在训练集拟合好，独立验证EV仅0.314。
旧Critic对同一新验证轨迹EV仍为0.842，说明问题不能简单归咎于验证样本更难。
扩至48首独立训练音乐、96episode后，256epoch仍明显过拟合。固定MC银行
扫描表明96epoch验证MSE最低，随后按同一设置重新做完整真实采集与预热：

* 48首训练音乐、96个训练episode，32个独立验证episode；都执行到music_end
  或真实物理失败，行政截断不作为完整MC标签。
* 96epoch，原有混合比例0/0.5/1对照后选纯MC；验证MSE762.871、EV0.670941。
* 真实预热共1202.54秒，通过最低EV0.60及MSE改善门槛。
* 真实折扣保持gamma=0.99每0.5秒，按实际控制步计算，50Hz已积分奖励不再次乘dt。
* 初始化SHA：``f0763ea30f01aa2267a5ea9571aa97c63141be28a97c157e5e67c34573e7136e``。
  两机字节一致，源码指纹严格匹配；含Critic与非空Adam，不是完整训练恢复。

这不是旧EV0.885的等价复现。新Critic仍低估部分长曲回报，周期完整MC是正式
训练的必要校准，短片段bootstrap标签上的高EV不能替代长期价值质量。

当前源码下Stage1完整test基线是22个独立音乐组、44个固定任务：40个正常结束、
4个真实物理失败、无行政截断。执行长度6.02至173.36秒，实体最大硬限位超量
0.00139828rad，GENMO参考0.22963071rad。两者不能混成一个越界数字。
八份权威journal的SHA、完整控制记录及四子步均核验通过。

这里“完整歌曲”指完整可用配对样本，不冒充未裁剪原录音。val和test按当前
第二阶段清单音乐组划分，不保证Stage1预训练从未见过相关音频。

------------------

独立技术检查完成2轮更新、正常退出、原目录恢复至第3轮。Actor Adam累计
14到20步、Critic224到320步；BC控制器、8rank游标/RNG、资源和策略版本继续

通过。该技术检查刻意未预热Critic，只证明执行和恢复正确，不作学习收益证据。

恢复后的末次评估有一次rank07卡在Kit/Vulkan初始化，尚未开始物理采样。
600秒启动限时后现有重试机制回收该进程，独立重试成功，最终正常退出；总
会话983.29秒，不能用114秒普通轮隐藏该成本。原失败启动证据保留，这类偶发
依赖启动问题尚未根治，常驻世界减少重复启动机会。

正式训练不设总墙钟时限，最多累计500个接受的PPO外层迭代。SIGINT/SIGTERM
安全停止、完整checkpoint、资源/磁盘保护、参考提交截止、部署推理预算和物理
失败终止保持。KL回滚不增加接受轮，但仍记实际采样和优化尝试预算。

有限对照与正式选型
------------------

新P1/P2各100接受轮，唯一主动算法差别是学习率控制。P1固定1e-7；P2从1e-7
开始，在[5e-8,2e-6]内按最大单去噪步平均坐标KL目标0.005调整。硬限制保持
全20步平均0.002、最大单步0.01、P95为0.01。两组训练规模、BC、Critic初始化、
行为、物理、27独立音乐组54任务验证相同，初始回报均34.09725399027207。

在结果前写定的规则保存在 ``pilot_selection_rules.json``：以同任务每秒回报
的来源等权、音乐簇配对90%区间判断P2是否明确优于P1；活动度不少于初始80%，
失败不增加，来源回报不低于初始5%以上。实体最大硬边界超量不超过0.005rad，
触硬边界控制比例增量不超过0.005；参考边界单列。这是候选对照门槛，不是
实机安全认证。无明确收益优先固定学习率，并如实标记收益尚未证明。

独立test整曲用于选型后复核，不用它反复调参。两个配置各只有一个训练随机
种子，音乐簇区间不能覆盖训练种子的全部不确定性。相同接受轮数对应相同名义
工作量，实际控制数、优化步数、BC量、MC工作量及全程时间必须另外报告。

正式参数、两组最终对照和启动记录待有限对照完成后补入。

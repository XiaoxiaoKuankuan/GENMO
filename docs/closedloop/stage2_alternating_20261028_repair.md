## 根 SO(3) 数值投影与隐式梯度

`reference_constraints.py` 保留十帧与已提交前两帧、真实名义 halo 的有限时域约束。新 `so3_projection.py` 将数值求解和反向微分分离。

数值前向仍求解最接近 Adapter 原始残差的受约束问题：

\[
\min_x \tfrac12\|x-y\|^2,\qquad c(x,h)\le 0,
\]

其中 `y` 是原始提案，`h` 包含已提交历史和名义根姿态。前向以 float64 求解，对内部约束留数值安全余量；转换成实际 float32 输出后重新计算 SO(3) 角速度、角加速度及 certificate。内部余量不改变对外 `3 rad/s²` 预算，不通过放宽 certificate tolerance 放行。

反向根据最终活跃约束求非线性 KKT 系统的导数，包含拉格朗日 Hessian 以及历史锚点、名义旋转和约束边界的梯度。SQP 迭代过程不保留庞大的展开图；这不等于阻断 Adapter 梯度，也不是把投影假定成恒等映射的直通估计。

数值前向使用真实拉格朗日曲率的 SQP，不能只用单位 Hessian 在高曲率角加速度面来回迭代。内点 QP 保留真实 KKT 残差最小的数值迭代，防止已到机器精度后继续缩小 slack 导致病态。小步长或线搜索停滞仅表示转入最终活跃非线性 KKT Newton 精化，不代表已收敛；精化同时检查完整约束、有限数值及驻点改进。最终需要反向的样本必须满足 stationarity 最大绝对残差不超过 `2e-6`，不能把可行但未达驻点的解送入隐式反向。

前向最多20次 SQP、8次最终 KKT 精化、3次内部安全重解；这些均为有限数值预算。角加速度内部初始余量为 `0.01 rad/s²`，角速度余量为 `1e-4 rad/s`，实际 FP32 输出仍以外部原预算严格复核。SQP 内部 merit 的 `1e-8` 数值零区只防止约 `1e-10` 的舍入误差乘罚权后压过末期目标改进，与原内部可行性精度一致，不改变外部运动约束或 certificate tolerance。

隐式反向求解

\[
\begin{bmatrix}H_L&A^T\\A&0\end{bmatrix}
\begin{bmatrix}u\\v\end{bmatrix}=
\begin{bmatrix}\nabla_x L\\0\end{bmatrix},\qquad
\nabla_\theta L=-\left(\partial_\theta r_{\rm stat}\right)^T u
-\left(\partial_\theta c_A\right)^T v.
\]

其中 `H_L` 是完整非线性拉格朗日 Hessian，`A` 是最终活跃约束 Jacobian；反向不使用前向数值搜索的正定修正 Hessian。历史锚点、名义姿态、目标提案和上下界均进入上述参数导数。该导数对应局部活跃集合稳定时的解映射，不宣称非凸 SO(3) 问题有全局最优保证。

数值失败处理的边界如下：

1. 投影器优先进行有限次数内部安全重解，绝不返回已经确认不可行的参考。
2. 真实训练采集仅对异常掩码对应的环境重新 reset，最多两次；不发送坏动作，不写伪造转移。新 episode ID 阻止 Replay 跨 reset 拼接，旧片段按行政结束处理。
3. 评价不能用随机 reset 隐藏原初态失败；相应歌曲记为 `constraint_failure`。
4. 想象展开拒绝失败 microbatch，其他可行 microbatch 保留完整梯度，最终按实际有效样本数归一化。
5. 整轮没有可行样本时不执行、不计数 Adapter Adam。连续五轮全部拒绝后保存现场并停止该组，防止无限重复 WM 训练；其他 GPU 不受影响。
6. NaN/Inf、OOM、物理求解器异常和不能恢复的参考失败仍保留完整现场。

## SuperMimic 交替训练循环

正式方法仍是：当前 Adapter 真实采集 → 原 WM H8 递归状态监督 → 冻结 WM/Actor 的 H8/H16/H32 BPTT → 下一轮。没有 PPO、DPPO、额外控制网络、逐候选物理方向门禁或参数缩放信任域。

共同设置：2048 真实环境，初始 64 向量步填 Replay，100 个 WM-only 交替循环，之后每轮交替采 2/3 个向量控制步、10 次 WM 更新。WM batch 2048、窗口 H8、LR `3e-5`；Adapter batch 1024、microbatch 32、LR `3e-5`；gamma `0.99`，梯度范数裁剪 `1.0`。第一阶段预算为每卡 **50 次有限 Adapter Adam 更新**，不是恢复旧实验或直接重复原 1000 次长搜索。

WM 保留原结构和预训练权重，所有 H8 步都有真实状态监督，递归动作是 Replay 保存的实际执行动作。正式路径没有重新加入参考响应、奖励响应、切向损失或额外长时监督。

输入/输出 RunningNorm 继承原 mean/var/count 与上限。达到原计数上限的行为明确记录，不能清空统计伪装适应。`wm_distribution.py` 提供原统计分布诊断及保持函数不变的数学迁移工具；是否迁移必须由真实数据证据和函数等价检查决定，默认新训练没有擅自重置预训练统计。

## Critic 的处理

八份新配置均为 `critic_enabled: false`，正式入口拒绝开启未经独立校准的旧想象 Critic。新实验的 Adapter 目标只有 H 步折扣奖励，不存在终端价值梯度，也不做无意义的 Critic 优化。完整 checkpoint 仍保存 Critic 和其优化器容器，禁用时优化器状态可以为空。

旧 Critic 失败权重保留。新增真实回报锚定、真实终止 MC 后缀、独立 validation/audit 校准和价值上界的工具，属于后续明确重新启用前的条件，不能把 value clamp 或想象 EV 当作真实校准。按当前每步奖励上界 `0.1` 与 `gamma=0.99`，无限时域价值上界为 10；有限剩余时间使用对应更紧的几何级数上界。

本轮正确表述是“未校准价值已隔离于 Adapter”，而不是“旧 Critic 已经训练好”。

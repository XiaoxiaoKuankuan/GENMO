# 2026-10-28 Stage2-A 八卡交替训练修复

本文说明 `feature/stage2-supermimic-adapter` 对 `alternating_20261027_2226_r2` 失败实验的修复实现、运行合同和证据边界。旧 checkpoint、日志和原始约束失败现场保留；旧模型先进行真实配对评价，新实验从零 Adapter 与原预训练 WM 初始化。实现完成、CPU 回归通过或实际 Adam 更新均不能单独证明真实舞蹈质量提高。

## 冻结资产与目标

- GENMO 缓存、SuperMimic Actor 和 Actor normalizer 冻结。
- Adapter 保持 `2654→512→512→256→270`，三隐藏层 SiLU、独立十帧 `10×27` 输出、原 SO(3) 组合；没有增加特权输入。
- 原始 GENMO 名义参考始终是 Tracking 和精度目标；修正参考只输入冻结 Actor。
- 根 XY 残差关闭；八组中 GPU7 额外关闭根姿态三个残差通道，仍保持完整 270 维合同。
- 原 SuperMimic 六项 Tracking 和 action-rate 不变；音乐权重 `1e-4`，软关节限位成本及额外 body angular velocity Huber 关闭。
- q、qd、身体姿态、局部根位移精度及必要参考正则沿用共同权重。所有八组均关闭未经真实回报校准的 Critic。

2026-10-28 较早一次指令曾取消根附加角加速度约束；本次最新任务明确要求在实际输出精度下满足 `3 rad/s²`，因此新配置重新启用该约束。它是修正参考相对名义参考的附加预算，不是新增机器人状态或硬件极限。

## 原失败模型的真实配对评价

入口为 `tools/evaluate_stage2_alternating_checkpoints.py`，读取旧实验各组自己的完整失败 checkpoint。评价不执行优化器更新，不更新归一化，使用冻结 Actor 和原 GENMO 缓存。

同一歌曲依次执行零 Adapter、重复零 Adapter 和已有 Adapter，三者使用相同真实初态与物理参数，无探索噪声。逐歌记录初态 SHA256、xi SHA256、共同评价预算，并在 `paired_comparison` 中核验一致性。重复零 Adapter 用于展示仿真重复噪声，不把噪声范围内的微小差异认定为改善。

报告同时保存：

- 原 SM 六项 Tracking，实际已执行前缀均值，以及共同预算归一化累计 Tracking。
- 关节 q/qd RMSE、身体姿态误差、原始根位置 RMSE。
- jerk、由真实求解器接触与共享实际 FK 计算的脚滑。
- 整歌完成率、真实失败时间、动作幅度和原离散音乐指标。
- 参考不可执行与真实物理失败分别计数；不可执行参考不得发送给仿真器。

已经结束的 episode 不再产生后续参考或补奖励。提前终止歌曲的共同预算分母包含未执行时段，因此不能用好看的短前缀平均分冒充整歌改善。短评价的 `administrative_truncation` 不等于整歌完成。

旧模型原算法效果须使用冻结的旧实现快照评价；新投影对旧模型的影响属于另一个明确标识的对照，不能混为同一结果。评价工具的实现错误和未完成产物不进入质量结论。

## 根 SO(3) 数值投影与隐式梯度

`reference_constraints.py` 保留十帧与已提交前两帧、真实名义 halo 的有限时域约束。新 `so3_projection.py` 将数值求解和反向微分分离。

数值前向仍求解最接近 Adapter 原始残差的受约束问题：

\[
\min_x \tfrac12\|x-y\|^2,\qquad c(x,h)\le 0,
\]

其中 `y` 是原始提案，`h` 包含已提交历史和名义根姿态。前向以 float64 求解，对内部约束留数值安全余量；转换成实际 float32 输出后重新计算 SO(3) 角速度、角加速度及 certificate。内部余量不改变对外 `3 rad/s²` 预算，不通过放宽 certificate tolerance 放行。

反向根据最终活跃约束求非线性 KKT 系统的导数，包含拉格朗日 Hessian 以及历史锚点、名义旋转和约束边界的梯度。SQP 迭代过程不保留庞大的展开图；这不等于阻断 Adapter 梯度，也不是把投影假定成恒等映射的直通估计。

运行必须记录 QP/SQP 活跃数量、SQP 迭代次数、float64 可行性残差、stationarity 残差、float32 转换后误差和最终 certificate。八份旧失败现场、活跃面有限差分和 CUDA profiler 是本次必须给出的独立证据。**在这些证据完成前，不能仅根据实现采用隐式微分就宣称八份现场均通过、梯度正确或 H32 已达到某个加速比例。**

数值失败处理的边界如下：

1. 投影器优先进行有限次数内部安全重解，绝不返回已经确认不可行的参考。
2. 真实训练采集仅对异常掩码对应的环境重新 reset，最多两次；不发送坏动作，不写伪造转移。新 episode ID 阻止 Replay 跨 reset 拼接，旧片段按行政结束处理。
3. 评价不能用随机 reset 隐藏原初态失败；相应歌曲记为 `constraint_failure`。
4. 想象展开拒绝失败 microbatch，其他可行 microbatch 保留完整梯度，最终按实际有效样本数归一化。
5. 整轮没有可行样本时不执行、不计数 Adapter Adam。连续五轮全部拒绝后保存现场并停止该组，防止无限重复 WM 训练；其他 GPU 不受影响。
6. NaN/Inf、OOM、物理求解器异常和不能恢复的参考失败仍保留完整现场。

## SuperMimic 交替训练循环

正式方法仍是：当前 Adapter 真实采集 → 原 WM H8 递归状态监督 → 冻结 WM/Actor 的 H8/H16/H32 BPTT → 下一轮。没有 PPO、DPPO、额外控制网络、逐候选物理方向门禁或参数缩放信任域。

共同设置：2048 真实环境，初始 64 向量步填 Replay，100 个 WM-only 交替循环，之后每轮交替采 2/3 个向量控制步、10 次 WM 更新。WM batch 2048、窗口 H8、LR `3e-5`；Adapter batch 1024、microbatch 32、LR `3e-5`；gamma `0.99`，梯度范数裁剪 `1.0`。第一阶段预算为每卡 **50 次有限 Adapter Adam 更新**，不是恢复旧实验或直接重复原 1000 次长搜索。

WM 保留原结构和预训练权重，所有 H8 步都有真实状态监督，递归动作是 Replay 保存的实际执行动作。正式路径没有重新加入参考响应、奖励响应、切向损失或额外长时监督。

输入/输出 RunningNorm 继承原 mean/var/count 与上限。达到原计数上限的行为明确记录，不能清空统计伪装适应。`wm_distribution.py` 提供原统计分布诊断及保持函数不变的数学迁移工具；是否迁移必须由真实数据证据和函数等价检查决定，默认新训练没有擅自重置预训练统计。

## Critic 的处理

八份新配置均为 `critic_enabled: false`，正式入口拒绝开启未经独立校准的旧想象 Critic。新实验的 Adapter 目标只有 H 步折扣奖励，不存在终端价值梯度，也不做无意义的 Critic 优化。完整 checkpoint 仍保存 Critic 和其优化器容器，禁用时优化器状态可以为空。

旧 Critic 失败权重保留。新增真实回报锚定、真实终止 MC 后缀、独立 validation/audit 校准和价值上界的工具，属于后续明确重新启用前的条件，不能把 value clamp 或想象 EV 当作真实校准。按当前每步奖励上界 `0.1` 与 `gamma=0.99`，无限时域价值上界为 10；有限剩余时间使用对应更紧的几何级数上界。

本轮正确表述是“未校准价值已隔离于 Adapter”，而不是“旧 Critic 已经训练好”。

## 每次更新的补偿有效性记录

`update_diagnostics.py` 对多歌曲真实因果起点保存更新前后分布：

- 网络 raw residual、投影后 residual 与二者差异。
- 下一已提交第一帧的残差、关节 q/qd、根位置和 SO(3) 姿态变化。
- Goal 与冻结 Actor 控制动作变化。
- 投影后更新／原始更新的传播比例和第一帧传播比例。
- 完整 BPTT 目标对初始想象步 raw residual、投影 residual、Goal、动作的梯度范数，投影前后梯度比例、夹角及阻断比例。

真实采集另记录六项 Tracking、实际精度误差和动作变化，明确标记为训练分布指标。它们不具有固定配对性质，不能代替真实评价。Tanh 未饱和、参数非零变化或 Goal 改变仅是优化诊断，不构成运动改善结论。

`torch.profiler.record_function` 为 Adapter、Actor、WM、参考投影、仿射 QP、SO(3) SQP、隐式 KKT backward 和完整 BPTT backward 标记独立范围。H8/H16/H32 更新耗时应报告真实 batch/microbatch、活跃约束比例与显存，不能拿单次 MLP 推理时间代替完整优化器更新耗时。

## 评价、best/latest 与恢复

- 更新 0、5、10：同歌曲、同初态、无探索的 256 控制步固定短时评价；单独保存前缀报告，不称整歌完成。
- 更新 20、40、50：固定整歌 validation 和 evaluation，执行到真实失败、参考失败或音乐结束。
- 零 Adapter 的短时及整歌基线分别保存，并逐歌核验初态/物理参数/预算身份，不能混用。
- validation 的整歌完成率、根 RMSE、共同预算 Tracking 与 jerk 共同用于选择完整 `best`；evaluation 只报告。短时 `best_short` 不与整歌混排。
- 每10次、评价点、第一次 Adapter 更新、WM 预热结束及异常保存完整 checkpoint；最近两份完整与 validation best 保留，编号轻量模型和评价报告保留。
- 所有新运行使用唯一新目录；不覆盖 `alternating_20261027_2226_r2` 或任何旧失败现场。
- 模型、三个优化器、WM/Critic 归一化、Replay、音乐/残差/时钟、任务随机流、探索随机流及通用 RNG 均进入恢复数据。
- 恢复真实仿真必须创建新 episode，不声称恢复求解器隐藏接触状态；Replay 仍保留，不跨新旧 episode 拼接窗口。
- 旧 checkpoint 缺少本轮新增元数据时补默认值并保留原计数；旧 checkpoint 没有独立探索 RNG 时明确记录新随机流初始化，不能声称位级续接。

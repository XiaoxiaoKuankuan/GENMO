价值判断与延迟

第6轮更新前真实行为版本5的case：15973转移、397121真实控制、18864计划，compact缺失0。
12368个完整保留观察时域的计划，原始新生成中心源帧均为15；当前计划首次中心消费为0.58秒，
约76.10%的本次转移控制早于首次前瞻消费，全部早于首次新自由帧中心消费。
这不等于全部奖励与新动作无关：前瞻影响早于中心执行；也不能把远期log-prob删掉。
仅保留第6窗口，跨窗消费统计为0只表示没有后续窗口证据，不能宣称没有跨窗影响。
窗口末待执行参考按右截断处理，未把未观察当作永远未消费；没有按plan_id重新搬移奖励。

真实失败尾部13条转移中，旧V相对该次无自举MC尾部平均高33.65、最大92.02回报单位；
但原GAE目标相对尾部MC平均差约0.604，已经利用真实终止纠正不少偏差。
失败后筛选的单次MC有随机性和选择偏差，此分组不能独自证明期望价值必然算错。
普通窗口尾部的lambda=1仍用同一Critic自举，不能把两种自举目标一致当成真实MC准确。

代码改动与理由
----------------

* configs/closedloop/stage2_objective_aware_validation.yaml：独立主线、合法预热导入、每3轮固定32任务、保存MC证据。
* actor_optimization.py：评估间隔从写死50/100改为严格正整数，使有限6轮能中途完整评估，不改变优化目标。
* value_credit_diagnostics.py：当前固定策略完整MC、八秒GAE/自举/真MC及局部风险分组；预测时刻用begin。
* mc_calibration.py：复用现有预测附加局部诊断；单次校准音乐数显式覆盖，不修改预热配置和验证池。
* train_closedloop_stage10.py/training.py：显式Critic-only校准，当前Actor新轨迹、原MC/TD候选、独立MSE改善才保留。
* summarize_stage2_continuous_validation.py：既有配对校验、来源等权、音乐cluster、共同时间前缀、数值与效率汇总。
* 新增统计/局部价值/配置/有限配额测试，根记录文本.md逐批追加；GMT源码与权重未修改。

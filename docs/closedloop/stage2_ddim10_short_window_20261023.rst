Stage2 十步扩散、两秒音乐与一秒动作
=================================

本记录说明2026-10-23在独立DPPO分支实施的短窗口采样、恢复修复及Server-2实测。
算法仍为完整链联合PPO，物理评价与接受优化步分别记录；推理变快不等于强化学习有效。

实际配置
--------

正式配置为 ``configs/closedloop/stage2_ddim10_last5_motion30_server2.yaml``。
GENMO分支为 ``feature/stage2-asymmetric-denoising``，GMT分支为
``feature/stage2-tracking-history``。共享工作树和旧运行资产保持原样。

* 扩散总数10步：4步冻结、5个随机步骤微调、1步冻结的确定性收尾。
  可训练索引是4至8；最终索引9没有高斯概率，保持冻结以维持现有PPO概率语义。
* 音乐60帧/2秒；动作30帧/1秒，均保持30Hz时间轴。动作窗口包括6至7帧已知前缀，
  因而典型新自由后缀约0.77至0.80秒，不是再从前缀末端向后多生成1秒。
* 保留Stage1网络参数结构、全部16层、48维历史和非对称Tracking90 Critic。
  短动作只保留前30帧扩散变量；后30个位置是零运动输入的音乐上下文，
  不参与动作概率和物理提交。所有60个音乐位置仍参与Transformer。
* CFG=2.5，eta=0.1，噪声序列为4个0.001及0.02/0.04/0.06/0.08/0.10/0。
* Actor名义最高LR=3e-6；8192条完整链每Mini-batch、Epoch=1、BC关闭。
  实际接受LR另记，不能把回溯后的学习率也称为3e-6。
* gamma=0.95、lambda=0.98；8秒采集窗口、随机运动起点、20秒片段超时自举不变。
  冻结GMT、50Hz控制、200Hz PhysX、现有奖励和终止定义不变。

为什么正式选择一秒
------------------

实测到达时刻量化到50Hz控制边界后约0.14至0.16秒，下一次合法生成起点通常为0.2秒。
GMT还需要未来0.2秒前瞻及插值/差分支持，0.5秒输出在等待下一份参考时会用尽。
参考合同测试已复现这一情况，不能用重复尾帧、额外外推或改写已执行参考掩盖。
因此15帧配置用于对照，30帧配置用于正式运行。

真实预热仍保留至少60帧bootstrap源参考；只把GENMO接管后的输出缩短。
最初把bootstrap一起裁短曾导致预热第444 tick参考不足，已在GENMO和GMT两侧修复。

修复原有第零轮重启
------------------

旧试更新出现有限log-ratio指数下溢，被当成原模型已损坏，导致整轮退出后恢复同一状态。
现在有限指数范围异常只拒绝并回滚候选，NaN/Inf仍报错；不裁ratio、不删样本。
候选回溯上限由5扩为10，最低候选比例为1/512，KL和完整PPO目标检查保持。
全部有限候选不合格时保留模型并采集下一批，明确记录零Actor更新，不能冒充学习成功。

首轮优化与保存前故障
------------------

首轮五个Mini-batch分别为8192/8192/8192/8192/3028条完整链，均通过候选检查。
同一批35796条链的PPO目标从约0升至0.018438，最终候选联合KL为0.009449。
五次接受LR分别为2.34375e-8、2.9296875e-8、1.8310546875e-8、
2.288818359375e-8、1.430511474609375e-8。首步3e-6的候选触发有限ratio范围
拒绝，回溯到第8档才同时改善完整目标并满足KL；新增10档回溯在此起作用。
这些是待整轮检查的候选，不等同于正式发布更新或物理效果改善。

整轮末尾的 ``reference_change_diagnostics`` 遗漏了旧索引19/20，十步核访问越界，
触发CUDA device-side assert，因此未发布首轮checkpoint。这是本次改动的遗漏，
不能把所有终止归咎于外部信号。现改用 ``policy.steps-1`` 和 ``policy.steps``，
报告中的最后随机均值索引也跟随 ``trainable_steps[-1]``。
新增测试先在CPU真实小网络复现同一IndexError，再覆盖10步15/30/60帧的
Adam更新后完整 ``final_kl``，以及旧20步4/10个随机微调步骤的末尾检查。
修复后短窗口、完整链概率及回溯组合70项通过；不绕过末尾检查。

并发任务留下的停止记录显示，17:28已请求本run在保存边界停止，17:34发现上述错误后

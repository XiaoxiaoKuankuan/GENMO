================================================

本报告评价 ``stage2_probability_20261019_physical`` 的100轮训练，
不是2026-10-19另一项全参数低学习率训练的100轮报告。只分析真实训练日志、
Stage1与第100轮固定GMT–PhysX配对评估和保存权重，不改变算法、奖励或配置。

结论与停止状态
----------------

这100轮有小幅、局部的真实物理收益，但没有形成全面、明显的跟踪提升。
固定验证集每秒回报提高0.375%，完成任务由29/32增加到30/32；
根位置与根姿态RMS误差分别降低4.42%与5.02%，腿关节基本持平、脚高度略差。
没有新增失败，但另外两个持续失败的任务都更早终止。不能将此解释为所有动作
都更贴合，或只要继续增加轮数就一定能够改善。

2026-10-20 11:23:13（服务器本地时间）正常退出，退出码0。
实际停在100轮、798次Actor更新，没有进入第101轮。
第100轮固定物理评估、独立MC验证与checkpoint保存完成后才退出；
11:24:13再次核验原torchrun及8个worker均不存在，GPU计算进程为空，
物理世界closed、无待处理环境、source_unchanged=true。
退出复用了同一学习版本的维护结果，没有再跑一遍评估挑选更好分数。

这次训练的 ``actor_trainable_scope=qpos_output``，只有原网络
``denoiser.final_layer.fc1/fc2`` 的权重、偏置四个张量发生变化。
Transformer主干及其余Actor状态与初始checkpoint逐位相同。
因此本结果仅说明输出头微调的收益与局限，没有解决或验证
“让Transformer参与学习，同时避免过度改变联合概率”的问题。

实验身份与比较方法
--------------------

* 服务器1；GENMO固定分支 ``feature/bumi-music-closedloop``，
  GMT固定分支 ``feature/bumi-frozen-gmt-backend``。
* 配置 ``configs/closedloop/stage2_qpos_output.yaml``；
  Actor LR=1e-6、联合PPO clip=0.10、epoch=1。
* 正式续训从第2轮恢复，启动提交GENMO ``21b8746``、GMT ``f689ab5``；
  检查时GENMO HEAD为 ``e745941``，会话绑定的运行源码未变化。
* Stage1 s595000 SHA256：
  ``51b522fbdeb0ec289e5ffc24e2fccca9888df90495f57f96714c1bb43c05f8e2``。
* 同一val子集16个独立音乐样本，每个使用42、1729两个种子，共32任务。
  AIOZ/AIST++/FineDance/Mine分别为4/2/5/5个音乐样本。
* 执行完整可用配对片段，直到音乐结束或真实物理失败；没有10秒截断。
  “完整”指数据中的可用配对样本，不保证是未经裁切的原始录音。
* 保留冻结GMT、原奖励、50Hz控制、200Hz物理和0.5秒上层周期；
  使用原随机20步生成核，15个冻结步骤、4个训练步骤、最后冻结确定性一步。
  此处不是确定性MuJoCo sim2sim测试。
* 生产配对比较器重新读取原episode及控制侧车，核验SHA、任务、噪声计划、
  奖励和执行身份；32任务全部保留，比较过程中没有优化模型。
  ``status=passed`` 只表示证据核验通过，不表示模型已经全面提升。

主要表格先求每个episode的平均指标，在来源内平均，最后四来源等权。
RMS为上述来源等权MSE的平方根，不是每个episode RMS的直接平均。
误差下降为好，每秒回报上升为好。TensorBoard跟踪图采用来源内控制时间加权，
与本文按episode平均的口径不同，不混合两种数值。

逐项失败与来源差异
--------------------

* FineDance075、seed1729：Stage1在103.60秒航向误差超限；
  第100轮完成126.02秒可用音乐片段，恢复成功。
* FineDance138、seed1729：两边都因 ``yaw_anchor_ori`` 终止，
  132.90秒变为126.76秒，提前6.14秒失败。
* AIST++ ``gPO_sFM_cAll_d11_mPO0_ch08``、seed42：两边都因
  ``yaw_anchor_ori`` 终止，43.88秒变为42.50秒，提前1.38秒失败。
* 另外29条任务两边均完成。上述失败事件是航向跟踪超限，不直接等同于摔倒。

每秒回报的来源变化分别为AIOZ -0.556%、AIST++ +0.331%、
FineDance +1.278%、Mine +0.583%。收益没有覆盖所有来源。
两个持续失败任务的每秒回报都略升但失败更早，说明每秒分数不能单独评价能力。

为排除不同终止时刻的暴露长度差异，另外比较每对任务双方都已执行到的共同前缀，
保留完整episode失败结果作为主评估。共同前缀根位置RMS下降4.181%、
根姿态下降5.026%，腿关节上升0.353%、脚高度上升1.446%。
主要方向没有改变；共同前缀根位置差的95%区间略跨零，改善强度不应夸大。
共同前缀目标活动度逐值一致，实际活动度增加0.295%，不支持“靠明显缩小动作换分”。

奖励组成、限位与Stage1保持
----------------------------

总每秒收益0.008956中，Tracking积分速率增加0.007482，约占83.5%；
终止事件罚分减轻贡献0.000930，约占10.4%。

接触惩罚减轻1.348%，命令惩罚略增。扭矩罚分绝对值很小，虽然相对下降39.2%，
不能将其当成主要收益。Music和Stability奖励均为0，未改变奖励设计。

原始全控制样本的限位聚合显示均值略改善、尾部未全面改善：

  软限位越界坐标比例2.4062%→2.3710%。

* 实际机器人平均cost为0.004209→0.004189；

这些限位量按实际消费/生成范围分别计算，不把未执行的生成参考冒充机器人运动。
两模型执行时长有差异，尾部最大值仅为本批实际观察值，不作总体极值结论。
固定Stage1监督验证loss为4.325126→4.324559，基本持平；
未见这批验证样本上的明显BC能力退化，但它不是音乐语义质量或物理收益证明。

训练过程与Critic
------------------

两个会话合并后完整覆盖第1～100轮，无重复、无缺轮：

* 计划798次Actor更新，实际接受798次；拒绝0、回溯0、提前停止0。
* 有效链1,591,172条，学习率始终1e-6。798而非800是两个采集轮的链数不足整批。
* 只比较可训练输出头，累计参数变化RMS为2.54046e-5；
  可训练参数1,080,350个，四个张量均改变，其余Actor状态逐位不变。
* 每轮检查相对当轮行为策略的联合KL均值，前10轮平均0.020882，
  后10轮平均0.013605；100轮观测到的最大单链KL为0.553370。
  固定初始链上的累计漂移另有不同口径，不能与逐轮约束直接混用。
* 后10轮普通clip约52.12%，真正进入无梯度裁剪分支约28.34%；
  不能将普通clip过半解释为过半样本一定没有梯度。
* BC/PPO梯度范数比约0.1，后10轮余弦约0.030，没有强烈对冲证据。
* 非配对采集每秒回报：11～30轮2.42559、41～60轮2.41921、
  71～90轮2.42155、91～100轮2.42994，整体基本横盘。
  前10轮为2.47108，但FineDance控制时间占比由33.91%增加到49.25%，
  不能把训练采集窗口的首尾差直接解释成模型性能退化或提升。

当前独立完整MC验证32个episode、2374个上层transition，MSE=38.97645，
EV=0.95300，没有自举目标，也没有在本次验证中拟合或更新模型。
这是Critic当前价值预测总体可用的证据，不是Actor动作质量改善的证据。

新轨迹上的自举GAE诊断EV=0.99420；它与独立MC不是相同目标。
相对于初始固定GAE targets的旧诊断EV则由0.96731降到0.54550，
说明旧目标上的价值预测发生漂移。旧策略/旧自举目标不等于当前真实V；
应结合独立MC分析，不因新GAE曲线很漂亮而省略旧诊断，也不据旧目标下降
直接断言当前Critic失效。

普通训练轮墙钟共约11.425小时，平均411.29秒/轮；均值分别为环境213.14秒、
Actor PPO 40.16秒、BC 28.64秒、Critic 11.42秒、KL 111.56秒。
统计不含所有预热/独立评估/退出开销；Actor总时间与KL存在重叠，不能重复求和。
100轮尚未提供持续上升曲线，也不能从一次最终配对收益推断最终已经收敛。

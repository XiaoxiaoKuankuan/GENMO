一秒音乐动作与仅KL候选接受
========================

本记录对应2026-10-23用户明确要求：彻底删除完整PPO目标不能下降的额外门槛，
放宽KL，并将音乐和动作同步缩到30帧。实现位于GENMO
``feature/stage2-asymmetric-denoising``，配套GMT仍为
``feature/stage2-tracking-history``。旧工作树、模型、日志和运行目录保留。

接受逻辑
--------

``actor_backtracking.py`` 不再读取目标参考值，不再按目标增益拒绝候选，
不再继续试小学习率以选择最高PPO目标。首个数值有效且满足KL及原有裁剪饱和
条件的候选直接接受。``updater.py`` 保留整批PPO目标记录，目标下降本身不触发
回溯、提前停止或整轮回滚。``validate_stage2_full_chain.py`` 的离线判断同步修改。
现行完整链配置移除旧目标门槛字段；优化身份绑定
``finite_KL_only_first_qualified.v1``，不能把旧接受逻辑下的checkpoint无声恢复。

新配置为 ``configs/closedloop/stage2_ddim10_last5_motion30_music30_klrelaxed_server2.yaml``。

1秒动作包含原已知前缀，自由后缀长度仍由真实前缀预算决定。

--------------

      --output-dir /data1/user/liwei/GENMO_outputs/closedloop_stage10/stage2_music30_klonly_formal_<run_id> \

Stage2 联合概率敏感性诊断与参数范围候选
================================================

本报告区分真实行为数据上的概率/梯度实验、固定创新噪声的反事实参考变化，以及
真正的 GMT–PhysX 闭环评估。只有最后一类可以证明物理执行收益。ESS 仅是显式
离线归因指标，没有恢复为训练门限。旧数据、模型、奖励及失败样本均不删除。

代码与实验身份
----------------

GENMO 使用 ``feature/bumi-music-closedloop``，GMT 使用
``feature/bumi-frozen-gmt-backend``。服务器1的数值实验基于旧行为 case：

    kl_real_rollout/sessions/efe451fa-db55-4fff-b07f-efc6e75cdbdc/
    fixed_data_validation/iteration000001

其 ``case.json`` SHA256 为
``521fa2df20ebac193842ff66bd4abd2139c364f17c5f1a75fcd2b5435543ac88``。
共有6144条完整链，八卡各768条，每链参与概率的是15–18四步。
全局2048链小批时，epoch1为3次更新，epoch2为6次；它不是满额16384链的8/16次。

原方案为何不断降低学习率
------------------------

不是发现了高斯采样错误。31014912个自由坐标的旧标准化残差均值为0.000140735、
标准差0.99980379，三倍标准差尾率0.00269948，与标准正态理论0.00269980吻合。
独立 ``torch.distributions.Normal`` 与保存旧log-prob最大误差为9.094947e-13。
最高权重12条链用FP32旧均值、实际标准差和原sampling_noise重建，全部自由样本
逐位一致。FP64反解残差与原FP32噪声的约1.18e-5差异是重建舍入，不能解释成核错误。
四步实际标准差为0.04/0.06/0.08/0.10，不是std floor；本次没有修改这些值。

全参数首个Adam以LR=1e-6更新时：

* 完整链平均KL为13.40633，单坐标平均KL为0.00265577。
* 标准化均值变化RMS仅0.07288个旧标准差，但平均每链约5048个自由坐标累加。
* 普通clip比例99.8535%，实际失去梯度的active clip比例51.1719%。
* ESS仅1.44244条/6144条，即0.023477%；前0.1%最高权重链占99.9484%总权重。
* 最高权重来自FineDance193、rank7/env86/episode1/decision0、音乐frame256、
  前缀17、优势5.61255、log-ratio20.01233、KL30.72249，占82.5037%权重。

这同时包含高维小变化累加与模块/分组差异，不能简单归为单个异常坐标。
去噪15/16/17/18的KL比例分别为21.922/16.085/17.608/44.385%。
root模型运动特征、rotation6D、12腿关节、其余9关节分别占
2.757/4.361/40.532/52.350%；其余9关节占30%坐标但占52.350%KL。
最高1%坐标占16.291%KL，最高1%链只占3.574%KL。
带符号log-ratio跨坐标相消93.518%，所以不能用带符号比例冒充贡献占比。

完整全参数epoch2真正把LR压到1e-9的原因已定位到一条真实链：
FineDance142、rank4/env93/episode1/decision0，request_id为
``env93:episode1:decision:0:rank:4``。第4/5/6次接受更新后，该链KL为
1.56051/1.58703/1.59816，贴近候选单链上限1.6。第5次拒绝4次、第6次拒绝1次，
拒绝原因均只有 ``chain_joint_max``；全批平均KL仍约0.059。
后两次实际LR为4.76837e-9和2.98023e-9，参数RMS变化约2.19e-9和1.29e-9。
理想Adam增量有19.77%和33.22%在FP32参数减法中舍入为零，这是LR被压低后的
次生损失。此处没有ESS硬门限，也不是ESS触发了回退。

原全参数范围有211496736个参数。冷启动Adam的首步接近逐参数符号更新，
首次参数RMS变化9.92e-7，接近名义LR；不能把梯度裁剪系数0.000409理解成
Adam参数增量也相应缩小。相同真实Adam增量按模块隔离时，Transformer主干单独
引起KL5.01265，qpos输出MLP单独仅0.05117，差约98倍。这些非线性隔离结果不能相加。
接触头单独更新对完整链KL和冻结末步输出均无变化；扩大不必要的更新范围增加了
内部路径变化，不能保证最终动作收益。

BC/PPO在原全参数前三次更新中的余弦约0、-0.0199、-0.025，BC范数约为PPO的10%，
没有强烈BC抵消的证据。不能把小输出变化笼统归咎于BC。末步确定性网络的扰动增益
中位数约0.54–0.66，会衰减前面变化，但没有把变化完全抹掉。

实现、行为边界和验证
--------------------

* ``gaussian_probability.py`` 的可选坐标输出复用生产FP64异方差公式；
  ``probability_attribution.py`` 保留正负、绝对、相消、噪声尾率、权重和真实样本身份。
* ``attribution_runtime.py`` 使用同一ConditionGraphCache及实际transition kernel；
  ``actor_step_diagnostics.py`` 保存四步状态、确定性末步前后和解码参考。
* ``actor_scope.py`` 显式定义独立范围，写入优化身份；不新增Actor网络或修改Stage1结构。
  行屏蔽同时约束PPO/BC，原单组零weight_decay AdamW及回溯状态恢复保持成立。
* ``optimization_support.py`` 保留协同数值异常的FloatingPointError类别，使既有回退
  不会因包装成RuntimeError而错误失效。
* ``updater.py`` 只增加显式离线observer和单次实验上限；生产联合PPO未改成逐步clip。
* ``training_checkpoint.py`` 对离线候选导出使用只评估身份，绝不冒充训练恢复。
  旧case与当前配置仅实测延迟样本池/来源记录不同，显式迁移仍严格锁定物理时钟、
  prefix预算、噪声、奖励、资产及数据。两种身份均保存，不能把分布不同说成相同采集。
* ``reference_credit.py`` / ``env_adapter.py`` 可选保存紧凑执行来源v2；
  ``execution_provenance.py`` 递归追继承前缀。当前中心用窗口第10项，不把首次进入
  前瞻窗口当中心执行。GMT只增加只读源帧插值支持查询及对照测试，没有修改实际插值。
* ``tools/analyze_stage2_probability.py`` 以八卡不可变case对比尝试、回溯、接受、
  epoch1/2及模块隔离；``tools/attribute_stage2_actor_change.py`` 只读比较真实checkpoint。
  ``tools/analyze_stage2_reference_consumption.py`` 通过case SHA和逐链身份关联来源。
  其时间视图额外按真实control_begin区分窗口回看、中心和前瞻，并核验三类之和
  等于完整窗口支持。保留区间中仅出现在回看的帧不能称为前瞻，父plan继承前缀
  也可能继续贡献新plan未来插值，不能只根据plan所有权判断来源。

服务器1最终相关测试为161项通过、无跳过，包括独立Gaussian、坐标加和、零更新、
prefix/padding、全Autograd与流式梯度、微批/尾批、多卡归约、回滚、不同scope的
真实参数及矩约束、当前30Hz到50Hz插值、继承前缀、配置及只评估身份。
临时测试目录已自动清理，正式实验分析证据保留在独立outputs目录。

旧数据消费证据的限制
--------------------

旧6144链case在保存时已经去掉execution_trace和generated，没有足够证据重建全部
中心/前瞻消费过程。其0:15生成帧KL为零，15:30/30:45/45:60分别占
24.6365/37.2173/38.1462%，只能作为源帧归因，不能说后75%一定没有执行。
新前缀来源记录能区分plan所有权与真正生成来源；30Hz到50Hz插值的相邻源帧
按真实权重统计，继承前缀继续追父plan。

root前3维是heading局部平面位移增量和高度偏移，不是世界XYZ。root积分与
Transformer跨帧依赖意味着时间KL分组也不是完整因果分解：未直接消费的源帧
可能通过生成网络影响实际消费参考。严格物理收益仍需相同协议PhysX配对结果。

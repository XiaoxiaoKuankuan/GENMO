## 数值优化与四种根姿态定义

根旋转为`R_nominal Exp(d)`，数值目标仍是到本次十帧提案的最小二乘距离；已提交
前一帧/当前帧不可回写，halo为`d11=2*d10-d9`且名义第11帧必须真实存在。

1. `strict_so3`：最大根旋转补偿0.05rad，附加角速度0.3rad/s，附加角加速度3rad/s²。
2. `relaxed_so3`：只将附加角加速度变为6rad/s²。奖励里的加速度成本不变。
3. `smooth_so3`：仅根旋转三通道先构造三次时间轨迹，随后仍做strict投影。令
   `k=1,...,10, t=k/10, base=anchor+k(anchor-left)`，基函数为
   `B=[t(t+0.1), t(t+0.1)(t-0.5)]`，`c=B⁺(raw-base)`，拟合轨迹`base+Bc`。
   k=-1和k=0精确保留历史两点，每轴两自由系数由全部十个输出共同决定。其余24
   通道不平滑，外部仍是270维；保留普通可微最小二乘及SO(3)隐式梯度。
4. `no_root_orientation`：根旋转三通道乘零，跳过SO(3)求解；其他预算/输入不变。

QP先尝试活跃约束KKT，只有完整primal/dual/complementarity/stationarity证书通过
才接收；其余样本回退原双精度IPM，已收敛样本分块移出。最终非线性KKT及实际
FP32可行性证书不变。没有detach主梯度、直通梯度或放宽tolerance。

发现并修复原近活跃冗余面乘子剪除缺陷：同时删除所有负乘子可误删必要约束，
导致可行点被判为驻点残差0.0117；同输入独立NNLS能达到1.42e-9。仅在困难近驻点
样本重新识别紧活跃面、逐次移除最负乘子，并要求真实驻点残差改善。

平移上一计划的数值热启动已实现，但实测H8变慢（micro256约38.05秒，对照原17.20
秒），因此正式统一关闭。不能把热启动存在当作优化成功。

# Stage2：直接有界根姿态补偿与软连续性成本

2026-10-29，分支 `feature/stage2-supermimic-adapter`。本次按用户确认，取消根角加速度硬约束及其非线性求解链，保留可微的姿态连续性与速度成本，然后重新训练。

## 代码与执行合同

继承当前分支 c803179/51e2455/3879716 的直接参考路径。正式采集、WM想象和评价都不创建 `ReferenceProjection`，不调用QP、SQP、IPM、KKT或导数可行性证书。旧求解器和历史夹具只供旧研究复现，不会通过旧配置恢复到新正式入口。

Adapter仍为2654→512→512→256→270，三个SiLU隐藏层。十帧独立输出保持小幅Tanh映射，根旋转向量范数最多0.05rad；根XY关闭，根高度和21关节输出保留。根旋转为 `R_corrected[k] = R_nominal[k] Exp(d[k])`，不作低通、样条或额外控制。原参考只读，当前已提交锚点保留，真实名义第11点加 `2*d10-d9` 仅作导数halo。

这是沿用当前直接参考实现：关节和根高度也不恢复旧导数QP，不会暗中将以前的硬预算加回来。NaN/Inf、实际动作出口、真实求解器异常与物理终止保护保持。旋转参考的硬角加速度上限不再存在，不应再宣称输出满足3或6rad/s²。

## 两项软成本

`precision.py::root_reference_costs`不修改参考，只计算奖励；所有输入和历史保留计算图。当前时刻、未来十帧以及halo的校正/名义旋转分别记为R与R0，dt=0.02：

`w[k] = Log(R[k+1] R[k]^T) / dt`

`C_velocity = mean Huber((w[k]-w0[k]) / 0.3)`

只惩罚附加角速度，原舞蹈转身不会被当作异常。当前→新第一帧与第10帧→halo均在范围内。不计算角加速度，不据此拒样。

前一周期计划后九帧与当前计划前九帧是相同绝对时刻；用SO(3)测地差计算：

`C_continuity = valid_previous * mean Huber(Log(Exp(d_old[1:])^T Exp(d_new[:9])) / 0.05)`

首计划无旧窗口时为零。不把残差当增量，不对过去已执行姿态重写。均值覆盖时刻和三个旋转分量。

总目标只新增 `-dt*(0.002*C_velocity + 0.001*C_continuity)`，dt只乘一次。0.3rad/s与0.05rad只是归一化尺度，不是运动限值；成本独立于执行精度总权重，没有角加速度、全关节平滑、控制动作偏离或投影距离成本。默认两项权重为零以保留旧直接参考评价语义；本轮八份配置显式启用。

原SM六项权重不变。用户指定尺度为根位置0.2m、根姿态0.3rad、身体位置0.1m、身体姿态0.15rad。真实终止仍是高度偏差大于0.2m或根姿态重力投影z差大于0.6，均相对原始GENMO参考。音乐1e-4，软关节限位、额外body_w Huber、Critic终端价值均关闭。

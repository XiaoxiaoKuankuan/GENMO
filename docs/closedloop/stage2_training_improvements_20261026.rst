第二阶段五项训练改进（2026-10-26）
================================

本批实现位于已授权独立工作树 ``rolling/GENMO``，分支为
``feature/bumi-continuous-rolling``。目标是让正式训练能够持续学习，并用更有代表性
的物理片段观察效果。没有更改奖励、Actor输入、冻结GMT、扩散采样核、学习率或半马尔可夫GAE，
没有启动当前Actor的完整轨迹MC。

修改内容
--------

1. ``learning_guards.py``、``training.py`` 与监督器共同读取
   ``evaluation.quality_action``。正式配置为 ``report_only``：质量变化写报告和checkpoint，
   不写新停止文件、不回退整场训练。显式 ``stop`` 仍可用于独立实验。旧停止事件保留为历史；
   报告模式恢复时不继续执行旧停止指令。非有限数值、协议错误仍报错。
2. ``critic_validation.py`` 仅按当前episode留出MSE选择Critic及对应Adam。
   初始固定自举标签只诊断，不再否决当前拟合改善。``critic_diagnostics.py`` 报告困难区间
   的数量、RMSE、偏差及EV；事后标签不进入模型。只有本轮实际观察到失败时才标出此前5秒，
   音乐位置超过100秒与连续物理执行超过100秒分开，零样本输出缺测，不能冒充改善。
3. ``robofft/updater.py`` 把代理裁剪饱和改为“保留本epoch并结束剩余epoch”。
   固定噪声参考变化超过现有约束时仍回退本epoch及Adam；实际保留和尝试次数分别记录。
4. 正式配置每10轮评估每来源4首独立音乐、双种子、最多20秒，使用已有mixed起点。
   平均评估任务数/轮与此前每5轮8首基本一致。报告新增音乐级改善比例、中位数、P10及
   按训练来源比例加权回报；音乐两个种子先合并，不伪装成两首独立样本。短曲中段起点可能仍为0。
5. ``adaptive_sampling.py``、``time_sampling.py`` 与训练采集器连接真实执行反馈。
   80%任务继续共享无放回bin覆盖，20%按全局困难度有放回抽样。任务均使用当前Actor重新生成。
   优先级由起点bin之后的腿关节、根高和非偏航误差及物理失败构成，表示该起点窗口难度，
   不是精确的动作信用分配。优先级限制在[1,3]，归一化后每bin及每首音乐的自适应概率
   均不超过均匀bin基准的3倍。20秒截断是删失观察，PPO切分不是失败，预热失败不提高优先级。
   每轮仅跨卡合并新增统计，EMA、待合并增量、RNG、覆盖游标和两类抽样次数随checkpoint保存。

恢复与初始化
------------

开启自适应会改变采样分布，因此从旧正式实验使用显式
``--initialize-robofft-variant <完整checkpoint> --future-critic-formal`` 进入新的输出目录。
Actor、Critic及两个Adam保留；重新计轮，采样统计重新建立，旧rollout不重用，不继承新分布的MC验收结论。
新实验自身使用 ``--resume latest`` 恢复完整采样统计及学习状态。旧正式目录与停止记录保持原样。

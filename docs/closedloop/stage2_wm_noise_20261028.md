## Critic：高估有独立于想象标签的直接证据

读取旧 GPU1 第 16 次更新 Critic，在上述 64 个固定**真实**初态上直接预测，得到：

| 指标 | 值 |
|---|---:|
| 原始未裁剪价值均值 | 16.13904 |
| 最小值 | 10.33102 |
| 最大值 | 26.25450 |
| 超过真实回报上界 10 的比例 | 100% |
| Critic 输入 RunningNorm count | 147456 |

这里没有利用 Critic 自己生成的 GAE 标签评判好坏。现有六项 Tracking 权重之和
为 5，原 SM 奖励已乘 0.02，所以每步最大 0.1；其他启用的成本和音乐项均非正。
因此在 gamma=0.99、continuation∈[0,1] 时：

\[
V(s)\leq\sum_{t=0}^{\infty}0.99^t\,0.1=10.
\]

代码检查发现两个需要隔离的机制：

1. `critic_update()` 的监督标签完全由当前想象轨迹和同一个 Critic 自举生成，
   没有真实回报锚点。对自身标签的 MSE/EV 好并不证明实际回报标尺正确。
2. `critic.norm.update(X)` 会直接改变归一化坐标，而首层网络权重不做对应变换；
   随后又使用改变后的 `critic(X)` 生成下一批自举标签。它能引起价值函数跳变。

λ-return 公式本身没有发现把 gamma 或奖励 dt 重复使用的问题。仅凭这两处机制
不能断言每一种对高估贡献了多少；因此本轮直接关闭未经校准的终端梯度和 Critic
优化，而不是靠减 LR、裁剪梯度或把值截到 10 就声称校准完成。

新增 `critic_calibration.py` 提供后续明确恢复 Critic 的必要实现：

- `real_mc_suffixes()`：只由同 episode、逐帧连续、最终观测到真实终止的奖励生成
  MC 后缀；截断、缺帧和跨 reset 不补值。随机中途起点仍明确称后缀，不称整歌。
- `real_anchor_loss()`：只接受 train 真实完整标签进行拟合；不以验证歌曲训练。
- `physical_calibration()`：独立 validation/audit 逐歌曲检查未裁剪价值、真实
  MC MSE/EV、真实 train 常数基线及上界违规。
- `terminal_value_allowed()`：必须显式启用、实际做过真实锚定，并独立校准通过。
- `bounded_terminal_value()`：额外保证真实回报上界；超过上界的梯度是真实零梯度，
  没有直通估计。该保护不能替代独立校准。
- `preserve_critic_input_function()`：若更新输入统计，同步重参数化首层，防止
  仅修改 norm 使价值函数突跳。

**本轮尚未重新训练或校准旧 Critic；新正式配置全部关闭 Critic。** 这是隔离已证实
的错误价值梯度，不是宣称旧 Critic 已被修好。

## 探索噪声分布对比的实际边界

下表均是旧 Adapter 实际轨迹上的 H32 预测；模型没有在本次对照中更新。

| 实际噪声 | 原 WM qd RMSE | 旧 WM qd RMSE | 旧 WM body_w RMSE |
|---|---:|---:|---:|
| 0 | 0.19012 | 0.17684 | 0.20763 |
| 0.01 | 0.15331 | 0.14709 | 0.18272 |
| 0.03 | 0.17235 | 0.16093 | 0.18543 |
| 90% 0.01 + 10% 0.1 | 0.17084 | 0.16517 | 0.19133 |

噪声会改变真实轨迹和接触，所以不能凭 0.01 这一列较低就断言其训练效果最佳。
这份固定窗口支持缩小常规探索并保留少量较大探索作为独立消融，不支持“噪声已被
证明是所有训练失败的唯一原因”。本轮没有进行四份新 WM 的拟合对照。

已有 GPU4 Adapter 在同一真实历史下相对零参考 Actor 的动作 RMS 变化平均为
**0.05429**，参考残差 RMS 为 **0.00656**；它已经不是第一次更新时约 0.004 的
动作改变量。因此讨论噪声与信号比例必须引用对应更新版本，不能长期沿用首次更新
的探针值。

## RunningNorm：先诊断，当前不擅自重置

原 WM 和旧独立 WM 的 input/output count 都是 **200003584**，超过原上限 2e8，
所以原 `RunningNorm.update` 不再改变统计。

本次 64 歌真实窗口中，输入均值偏移的 P95 约 **0.45～0.47 个旧标准差**，最大
约 **0.947**；没有字段超过 2 个旧标准差。目标均值偏移 P95 约 **0.15**。部分
目标标准差相对原统计增大到约 **2.45 倍**，值得持续报告，但没有证据要求现在
粗暴清空预训练统计。

因此新正式训练默认仍保留预训练统计。`wm_distribution.py` 提供可选的、数学上
保持物理预测函数不变的迁移，若未来真实分布确需调整再显式使用：

设旧输入归一化为 \((x-\mu)/\sigma\)，新统计为 \(\mu',\sigma'\)，则首层：

\[
W'_1=W_1\operatorname{diag}(\sigma'/\sigma),\qquad
b'_1=b_1+W_1(\mu'-\mu)/\sigma.
\]

输出原物理增量为 \(y=\sigma_y f(x)+\mu_y\)，相应末层：

\[
W'_L=\operatorname{diag}(\sigma_y/\sigma'_y)W_L,\qquad
b'_L=(\sigma_y b_L+\mu_y-\mu'_y)/\sigma'_y.
\]

这些变换不修改 Actor，不增加预测头；真正保持迁移前后的状态预测与动作输入导数。
Adam 的首层 W/b 换元是耦合变换，不能假装把逐元素一二阶矩简单缩放就精确迁移。
因此如启用迁移，只显式重建首末受影响四个参数张量的 Adam 状态，保留中间层；
报告记录这一优化器边界。统计随后冻结，不能在下一轮又裸更新 norm 破坏函数。
原 RunningNorm 的 `max_count` 不是 state_dict 张量，完整恢复必须调用
`restore_rebased_normalization_policy()` 恢复报告中的冻结策略。

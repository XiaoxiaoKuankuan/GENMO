# Stage2-A：冻结GENMO参考的可微WM闭环补偿

本方法替代失败八组实验及双低通方案。当前只实现固定GENMO缓存的Stage2-A；Stage2-B没有启动，PPO、GENMO扩散更新、额外残差控制器均不属于本入口。方法是否成功以独立真实整歌为准，不能以Oracle、更新计数或WM损失代替。

## 数据和网络

- 冻结Stage1 GENMO、SuperMimic Actor及normalizer；GENMO缓存始终只读。
- Adapter仍为2654→512→512→256→270，三个SiLU隐藏层，末层零初始化，十帧独立有界绝对残差。关闭根XY通道，保留根高度、姿态及21关节。
- 输入保留原具名InputSpec：真实10×75控制历史、原始Goal570、可观测误差、历史计划与锚点、EDGE35音乐及mask。没有根世界位置、根速度、xi或未来真实状态。
- 物理50Hz控制、200Hz求解；音乐30Hz、统一600tick/s。第11名义点必须真实存在，d11=2d10−d9只服务导数，不成为第11个Goal。
- 名义参考、修正参考、执行状态分别存储。跟踪、精度及终止均以原始GENMO为目标。

## 十帧最近点投影

设网络提案为y，已提交的前帧/当前残差为d−1,d0。位置及关节通道求

    min_d  1/2 sum(i=1..10) ||di-yi||²
    subject to |di| <= amplitude_budget,
               |di-d(i-1)| <= added_velocity_budget * dt,
               |di-2d(i-1)+d(i-2)| <= added_acceleration_budget * dt².

约束包含i=1的已提交接缝，过去不回写。halo令末段附加速度相等、附加加速度为零。普通关节初始预算1rad/s、10rad/s²；踝关节0.5、5；根高度0.12m/s、1.2m/s²。这些是算法候选附加预算，不能称为硬件上限。

可行提案直接原样返回。不可行通道批量ADMM定位活跃面，十维KKT精化最近点，隐式反向同时作用于提案与历史锚点。GPU用Triton单核内迭代，避免每周期发射数千个小算子。零提案与零历史严格输出零；非零已提交历史下“未来必须全零”与接缝约束可能互相矛盾，不能宣称同时无条件保证。

根姿态使用R0_i Exp(di_rot)。真实附加角速度定义为

    dw_i = Log(Rcorr_i Rcorr_(i-1)^T)/dt - Log(R0_i R0_(i-1)^T)/dt.

约束||dw||≤0.3rad/s、||Δdw/dt||≤3rad/s²以及原0.05rad旋转幅值球。旋转向量分量导数先提供线性可行域，再用30变量SQP处理真实SO(3)约束；每个子问题仍最小化与原提案的距离。64首实际反例说明固定罚参数ADMM难以处理近乎平行的旋转活跃面，因此旋转子问题改用GPU批处理双精度原始—对偶内点法（最多40个Newton步），普通关节仍用融合ADMM。SQP最多60次线性化，已收敛样本保持解并提前退出；各层预算明确有界。约束矩阵按法向长度等价缩放改善条件数，SQP内部merit回溯抑制非线性振荡，和跨控制周期的低通没有相同的执行语义。

SO(3)问题是非线性的，此实现不能声称获得全局最近点；需以数值误差、实际可执行证书及独立有限差分核验。任何未通过证书的Goal不发送给物理。活跃面交点处只有广义导数，普通非退化区用有限差分检查。

## 精度与稳定目标

原SM六项Tracking与原action-rate原样使用，SM项已经乘dt。2026-10-27用户进一步要求关闭软关节限位：Stage2-A配置关闭执行关节的90%软范围罚项，同时将修正参考的同一软范围成本设为0；硬件/求解器范围、原MDP实现及参考速度/加速度预算均保留。原body位置/姿态会按实际根XY/yaw重锚，原root位置指数在大漂移时饱和，所以新增精度项直接比较原始GENMO。

五个Huber误差分别为：身体姿态SO(3)角、关节q、关节qd、身体角速度、相邻控制步根局部位移。内部比例固定0.30/0.25/0.20/0.15/0.10。身体姿态不重锚yaw；局部位移比较真实/想象的相邻状态差与相邻名义状态差。标尺只取训练歌曲零Adapter真实误差P75并加固定物理单位下限，评价集不拟合标尺。

    r = r_SM_six_and_action_rate_dt + dt * [1e-4 R_music - 原有残差/活动成本
                       - w_precision Σ ratio_k Huber(error_k/scale_k)
                       - w_action ||a-a_zero_same_history||²
                       - w_v C_added_reference_velocity - w_a C_added_reference_acceleration].

a_zero使用相同当前历史、原始Goal和冻结Actor，是局部动作对照，不冒充独立零策略整段轨迹。根旋转导数成本使用复合SO(3)后的实际dw及其差分。原action-rate保留，不重复添加第二份动作连续性惩罚。世界根位置非饱和误差继续报告；根XY没有输入和输出时默认不赋予支配优化的权重。脚滑只取求解器接触和实际足端速度，不对离散接触标签反传。

记录分项均值、各项在固定BPTT探针上的参数梯度范数及与完整目标梯度的余弦；探针样本数明确记录，不把首个microbatch统计冒充整个训练分布。

## 真实Oracle和参考响应

Oracle先对训练音乐合法时刻运行零策略，按实际关节/姿态误差保存因果起点。候选为小幅提前/滞后、可观测关节误差修正、可观测姿态修正、组合修正及旧beta对照。相同起点、历史和物理参数下并排真实执行，H8/H16/H32/H64记录动作、Goal、参考、真实状态、接触和重复噪声。

离线挑选收益最大的候选只证明局部可补偿性。Oracle不训练Adapter、不增加特权输入，也不证明在线输入已学到补偿规律。

WM真实监督同时包含连续状态窗口和reference-response：当前策略的正负参考经同一投影、冻结Actor得到21维动作，执行真实物理。比较原起点局部坐标中的根位移、SO(3)姿态、q和qd响应。初态不匹配、重复差过大、接触切换、终止和动作差不足的标签明确标为不可靠，不进入切向损失。

训练Replay只保存8步响应窗口，H16/H32报告直接使用完整实际采集序列，不做补齐。每10次WM监督在固定总预算内重新采样真实方向；失败完整参数候选的正反物理响应也进入后续响应监督。独立validation响应只报告、不拟合WM。所有方向报告绑定当前WM参数SHA与版本；源码SHA仅用于追溯。

## BPTT与真实参数信任域

从真实起点进入H8想象，仅在入口detach。内部状态、历史、计划、锚点及音乐记忆均保留计算图。Actor和WM参数冻结但保留输入梯度；想象使用拟合后的独立WM，不调用原bundle模型。

每次候选保存旧Adapter及Adam状态。WM-BPTT产生完整参数增量后，训练内部预留起点比较旧策略、重复、候选、反向候选；同时报告完整H8 autograd方向导数、模型有限参数差分和真实物理差分。按1、0.5、0.25、0.125缩放同一增量，只有收益超过重复噪声且原方向/状态/参考约束成立才接受。失败回滚模型和Adam，保存失败权重和真实数据。缩放接受的Adam保留本次梯度的一次矩估计，实际参数步长另记缩放系数，不冒充多次更新。

初期Critic明确未校准、终端价值关闭，三个优化器均完整保存。以后只有独立完整MC校准与终端价值梯度物理检查通过才能启用；当前入口没有自动启用逻辑。

连续3个候选失败即退出，每次修复50次WM更新；不以监督次数充当有效Adapter更新。训练歌曲内部safety起点选候选，validation/audit/evaluation不用于逐更新选择。未参与配对的环境继续实际采集，配对转移和并行训练转移分开报告。

# 十帧Adapter失败审计与A/B/C修复对照

分支：`feature/stage2-supermimic-adapter`；配套SM：`feature/genmo-worldmodel-bridge`。
运行范围仅Server-1。旧8组停止并保留，不能把本次从零初始化解释为旧模型续训。

## 已证实的失败机制

1. `vector_control.reference()`对独立残差作20ms差分。±3cm的位置约束没有约束速度，
   极端相邻点可以产生3m/s的前向速度差。halo还会延续末段差分。旧GPU7@3000和
   GPU5@1800在同4首评价歌的根位置RMSE均值分别5.41m和23.80m，零Adapter为0.091m。
   根平移单独消融分别1.96m和13.94m；全残差缩小至0.1倍后0.092m和0.684m。
   这是真实物理反事实，不是声称缩放即可训练成功。出处：Server-1
   `diagnosis_20261027_1115/channel_ablation/physical_ablation.json`。
2. SM body位置项按实际root XY/yaw重新锚定；root位置项是
   `0.01*exp(-distance²/0.3²)`，远距离梯度消失。现有终止只检查高度/姿态，
   所以完整歌曲完成率100%可以和24m漂移同时出现。Adapter输入对真实根水平平移
   不变是部署观测合同，本次不通过增加特权输入规避。
3. 原`vector_audit`只审计第一步残差/动作扰动且`terminal_value=False`，实际训练
   同时更新全参数、正则和Critic终端值。真实checkpoint最近Replay复核：GPU7@2400
   的H4终端/密集梯度比6.34，完整目标与Tracking梯度余弦-0.193；GPU5@900比58.89。
   方向审计曾在WM继续更新后被沿用。H1不能证明H8闭环参数更新可信。
4. 旧切向数据总围绕零Adapter动作采集，而后期动作偏离超过其0.02探测半径的100倍。
   原在线WM转移监督存在，但局部Jacobian监督中心与当前策略错位。
5. 1,000,000容量在2048环境下仅488个向量步，约9.76s。长歌MC起点先被淘汰，
   加上审计/切向频繁整体重置，八组日志的完整歌曲MC覆盖全部为0。
6. 更新有效性只看前32样本，零变化抛异常且异常路径不保存完整最后状态。GPU5@1800
   训练Replay探针中60.5%的float32 Tanh导数恰为0；参数变化不等于控制动作变化。

## 参考约束与不变合同

网络仍`2654→512→512→256→270`、三个SiLU隐藏层、末层零初始化。每个未来帧
独立输出27维绝对名义残差。所有组关闭根XY两个输出通道，保留270维合同；不增加
观测。B/C执行前对十个提案使用确定性、可微的两个一阶滤波器串联，系数beta=0.05：

```
stage_prev = (anchor - (1-beta)*left) / beta
stage_i = (1-beta)*stage_prev + beta*proposal_i
residual_i = (1-beta)*residual_prev + beta*stage_i
```

这不是新增网络隐藏层或端点插值。每个proposal_i都影响对应输出，十帧映射是满秩
下三角线性算子。`left/anchor`均为已提交姿态的名义残差，不回写过去。只提交第一帧
后，在下周期精确恢复stage状态。零Adapter从零锚点开始，完整Goal和Actor与原方法相同。

若输出界限为B，残差速度逐分量最多`2B*beta/dt`，加速度最多`4B*beta²/dt²`。
本次非踝关节上界0.5rad/s、2.5rad/s²，踝关节0.25rad/s、1.25rad/s²；根Z为
0.1m/s、0.5m/s²。这里是**相对名义参考的附加导数上界**。修正后绝对上界为实际
名义导数最大值加该预算，逐歌曲及逐关节输出在`reference_derivative_certificate.json`。
名义本身若不合理不能被称为约束已修复；其原始分布单独报告。

旋转向量在0.05rad球内凸组合后仍按SO(3)右组合。实际世界角速度从旋转矩阵差计算。
在已检查的0.5rad离散旋转增量证明域中，SO(3) log Lipschitz系数用保守1.1，
附加角速度上界0.275rad/s、角加速度保守上界27.5rad/s²。它们是硬预算，实际P95/P99
另报，不用旋转向量导数代替实际角速度。第11点严格`d11=2*d10-d9`，只用于导数，
第10到11段的残差速度连续、残差加速度为零；真实名义第11点必须存在。

## 目标、Critic与真实评价

SM原六项、XY/yaw身体对齐、原动作变化−0.1及实际关节限位−2均不改。音乐权重仍1e-4。
在原附加成本基础上，三组都预先固定加入：

```
root_non_saturating = ||executed_root_p - original_GENMO_root_p||²
reference_velocity = mean((corrected_v - nominal_v)² / 0.3²)
                   + mean((corrected_w - nominal_w)² / 0.5²)
                   + mean((corrected_qd - nominal_qd)²)
reward += -0.02 * (1.0 * root_non_saturating + 0.05 * reference_velocity)
```

这些奖励可以使用训练期物理状态，但不进入Adapter输入。参考速度成本不是硬约束的
替代。A/B本轮不启用Critic终端价值，只用H8密集完整目标；停止使用软生存率对未来
奖励缩放，真实/想象均使用实际终止掩码，歌曲结束不bootstrap。

Critic独立采集训练8歌、验证4歌，每歌固定初态及一份真实扰动，直到真实终止。
逐步奖励完整保存，特征每8步保留；按真实终点反算MC，绝不受WM环形Replay覆盖影响。
记录每首歌样本数、起点、长度、策略版本、失败与完整歌曲比例。训练集统计归一化，
验证数据不拟合。训练/验证逐歌EV、MSE、失败附近误差完整报告；不因总样本数大称合格。
Critic的物理位置改为相对当前名义根的位置误差，名义XY字段置零，并在原有6个空闲
Critic上下文槽中加入根误差平方、剩余折扣质量和结束时间基函数。输入维数仍2835，
避免要求网络通过两组绝对世界坐标学习差值或记住歌曲坐标；不改Adapter观测。
C用当前策略真实连续片段GAE，真正终止清零bootstrap，行政32步截断允许bootstrap；
Critic梯度不通过环境/WM反传给策略，未校准结果如实标注。
C的独立MC也使用相同latent高斯策略，避免用确定性均值策略的MC冒充探索策略价值；
完整物理比较则统一执行确定性均值策略。任务/初态与探索使用分开的随机流并保存。

评价使用原四首独立evaluation歌、固定初态和无噪声；同时给完成率、原始根RMSE、
Tracking、jerk、脚滑及参考导数分位数。早失败时另给`full_horizon_tracking`：已执行
原Tracking累计值除以预定整首步数，未执行尾部不伪造状态或音乐分数。只有执行前缀的
Tracking不能独立排名；关联矩阵同时记录六项、非饱和根成本、幅度、动作变化和脚滑。

## WM方向审计与预算

真实切向对以当前策略动作作中心；WM仍只监督真实连续转移和训练歌曲成对动作。
H1局部干预报告仅用于诊断。每个完整候选参数更新都同时做基线、重复基线、候选和
反向参数步的H8/H16闭环物理对照，使用0/50步真实因果前缀及四首audit歌曲。
记录WM版本及参数SHA、候选前后Adapter SHA、Critic SHA、完整目标、约束设置。
源码SHA仅追溯，不是恢复门禁。任何网络变化后旧审计不能放行新的更新。

分开报告：完整参数方向的模型autograd、模型候选收益差、真实候选收益差、Tracking差、
重复物理噪声、模型状态误差。高信噪比符号反向拒绝；至少半数case可辨识且总真实收益
超过噪声、状态误差满足原阈值，才允许该候选的H8更新。H16结果独立，不能由H8替代。
初始WM监督50步，失败后每轮修复50步，连续三轮失败即保存现场退出，不无限训练。

## A/B/C预算与概率核

三份配置在`configs/closedloop/stage2_adapter_repair_{a,b,c}_server1.yaml`。
每组1024环境、同初始化seed42/采样seed20261027、同任务/资产/评价，独立模型、优化器和Replay。
Adapter LR3e-5，所有组最多100次**完整批量Adam参数步**，25/50/100实际物理评价。
不是原八组参数搜索。A/B用当前WM的H8；C用真实仿真的潜变量策略梯度/PPO单epoch特例。

C的网络输出是270维Gaussian均值，固定latent std=0.2；关闭的20个根XY维度是确定性0，
联合概率只包含其余250维。真实执行保存原始latent，更新时重算该latent的新旧高斯
logprob；随后Tanh、SO(3)旋转球约束及二阶参考映射都是确定性控制过程。
不计算不可逆投影后的虚构密度，也不对SM动作计算Adapter概率。每次32真实向量步、
全批梯度累积、只做一次Adam步，明确与A/B相同更新计数。首轮没有重复epoch，PPO裁剪
因此主要保留精确概率核并为将来合法多epoch提供接口，不宣称已经利用多epoch效率。

每个异常保存最后有效Adapter、三个优化器、WM、Critic统计、短窗Replay、独立MC、RNG、
音乐/残差状态、未提交PPO批次和traceback。求解器隐藏状态不能恢复，恢复后新真实episode
必须另起；旧未提交在策略数据仅作证据，不作为新采样使用。失活更新诊断后暂停，不虚增
accepted计数。只有独立真实评价不再系统下降且出现稳定增益，才考虑扩展8卡。

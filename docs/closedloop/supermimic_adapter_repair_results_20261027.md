## 1. 核心失败机制：控制目标、价值梯度和验收对象不一致

| 代码位置 | 已证实的问题 | 本次实际改动与边界 |
|---|---|---|
| `vector_control.reference()`、`policy.py` | 原先只约束残差姿态幅值。20ms差分会把很小的位置/关节残差变成很大的速度目标，锚点接缝和halo同样受影响 | 保留三隐藏层/270维提案，增加确定性的可微二阶参考约束；根XY可关闭，Actor和观测合同不变 |
| SM `mdp.py:reward`、`vector_control.advance()` | body位置/姿态按实际root XY/yaw重新锚定；root位置指数项远离目标后接近零梯度；只检查高度/倾倒的终止允许水平漂移后仍“完成歌曲” | 原SM六项及对齐完全保留；另加原名义根误差平方成本和参考速度偏离成本，评价同时看原根RMSE、完成率、Tracking、jerk |
| `vector_audit.py`、原训练入口 | 原审计检查第一步残差/动作扰动，未检查实际全参数更新、正则与Critic终端目标，WM继续变化后还会沿用旧许可 | `parameter_audit.py`对完整候选参数步做H8/H16真实配对，绑定WM版本及网络参数SHA；H1仅为局部诊断 |
| `vector_collector.tangent_pairs()`、`repair_entry.py` | 旧局部动作响应数据围绕零Adapter；修复初版又遗漏循环内重新采集 | 当前策略动作作配对中心，每轮WM监督前刷新真实正负配对并记录身份；初版A0/B16保留为先导证据，不能冒充最终修复结果 |
| `vector_replay.py`、Critic数据路径 | 旧百万容量在实际2048环境下只保留488向量步，即9.76秒；长歌起点被覆盖，八组完整歌曲MC覆盖为0 | 新增`real_returns.py`，完整逐步真实回报独立保存，稀疏保存Critic特征；短窗WM环形缓冲不再决定MC是否完整 |
| `vector_control.critic_features()`、`GroupNormalizedCritic` | 跨歌曲绝对坐标、时间尺度和罕见失败数据不足；总EV不能代表失败附近价值可信 | 仅Critic使用相对原名义根误差、剩余折扣时间基函数及训练集归一化；另做真实困难状态校准，Adapter输入不变 |
| `vector_learning.adapter_update()` | 只检查前32个样本，Tanh失活后可能参数在变、动作不变；直接抛错丢失最近训练状态 | `update_diagnostics.py`固定8首训练歌、128个多时间探针，记录逐歌变化分布；无意义更新回滚并暂停，数值故障完整保存 |
| `vector_checkpoint.py`、异常入口 | 旧异常路径未保证保存最后有效网络、优化器与数据 | 保存三个优化器、WM、Critic统计、独立MC、Replay、RNG、音乐/残差状态、待处理批次和traceback；物理求解器隐藏状态无法逐步恢复，恢复必须新起真实episode |

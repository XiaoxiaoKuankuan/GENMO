- `simulation.sh`、`ac_start.launch`恢复基础频率2000、分频40，`plot_gmt_actions=false`保持。
- `load_ac_controller.launch`默认统一为2000/40；实机上层仍显式传入原500/10，不改变实机有效配置。

- 未改C++、模型、动作、机器人资产、PD、保护或9毫秒模拟延迟；无需编译，重启仿真加载。
  没有在用户运行中的仿真热改物理参数，也没有停止用户会话。

之前改变的是物理分辨率和底层更新间隔，不只是策略分频。`LeggedHWSim`随物理周期差分关节速度并更新PD力矩，
接触积分和延迟离散化也会受步长影响；`standDuration_=2*500`按循环数递增，导致站立过渡时间改变。
这些是需要排查的耦合因素，**并非已证明的旋转、抖动唯一根因**。

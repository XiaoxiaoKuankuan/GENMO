实际训练合同
------------

* 配置：``configs/closedloop/stage2_random20s_gamma095_server2.yaml``，同时作为
  本分支训练入口的默认配置；所有参数可直接在YAML中查看。
* 普通采集全部采用配对运动起点，standing_start_probability=0。沿用原音乐来源
  概率、合法随机时间bin、配对关节/根位姿/速度初始化和冻结GMT真实1秒预热。
* GENMO接管后的20秒才计入片段上限；600Hz时钟下结束tick为12600，其中最初
  600 tick为预热。音乐剩余不足片段上限时正常到音乐末尾，不补虚构动作。
* 8秒仅切PPO数据窗口。物理episode、参考与音乐继续，20秒计时不会从采集边界重算。
* 到20秒精确停止物理advance，terminated=False、truncated=True，以重置前真实
  Actor/Critic条件计算next_value。GAE不跨到下一次reset；物理失败和音乐自然结束
  尾值为零。失败与超时同刻发生时按失败，失败事件只计一次。
* gamma_upper=.95，lambda_upper=.98。控制周期折扣为gamma_upper**(1/25)，按实际
  执行控制步数折扣，奖励已含20ms积分，不再乘dt。
* Value折扣半衰期6.7567秒，20秒权重0.128512；GAE还包含lambda，其组合衰减
  半衰期约4.8475秒。两者定义不同，不能把后者当作Value的折扣半衰期。
* 全部16层Transformer保持可训练，8192完整链mini-batch、Epoch=1，正式采集容量
  16384条上层链、至多2次计划Adam更新；实际次数由有效真实manifest决定。
* Actor使用四步联合密度之积形成一个完整链ratio：先求15～18四步联合log-ratio之和，
  再做一次PPO符号相关裁剪，不除自由坐标数，不对四步另加denoising discount。
  旧分支实际为逐步坐标平均代理，故本次同时对齐明确要求的完整链数学实现。
* 完整链clip=.1、目标感知回溯；名义Actor LR保留服务器2原统一3e-7，不自动移植
  原功能分支的分组LR。BC关闭，不构造监督数据支路，实际BC样本数为零。
* 60帧/30Hz、每0.5秒重规划、15+4+1、CFG=2.5、eta=.1、真实std_schedule和冻结
  Stage1前15步/末步均保持。Actor输入、Critic结构、原八项Tracking奖励、其余奖励、
  当前Stage2 reward_std、GMT权重、50Hz控制及200Hz仿真保持。
* ESS不作硬门限，不按单首新增失败停止训练。Critic质量报告保留但不作新增停训门禁；
  数值故障和不完整物理事务仍按原机制如实报错。

原第140轮数据的优势和消费审计
----------------------------

``old_case_audit02`` 只读审计了14319条上层记录及357886个真实控制步。逐步奖励
明细、事件并入末步的约定、600Hz区间及21点GMT窗口核对通过，未发现奖励区间重复。

最大优势来自FineDance077、音乐起点1085帧：标准化优势25.4857，原始优势60.1372。
用生产GAE线性分解，真实奖励累计项8.2230、价值项51.9142，二者之和与原标签一致；
该当前0.5秒区间真实奖励为1.0096。窗口尾部自举贡献61.5097包含在价值项中，不能
再作为第三项相加。该分解证明了信号的来源，不单独证明Critic的期望值估错。

优势最高1%的143条记录中，FineDance占109条（76.2%），整批该来源占约25.2%。
这组当前区间奖励均值1.1478，整批均值1.2369；不同音乐难度和延迟不同，不能仅凭
这项原始相关性判断动作优劣，更不能称为同状态候选比较。

在每条新生成动作自己的执行区间内，当前GMT中心仍来自此前计划的保护前缀，
357886个控制步均没有消费这条新计划自己的自由帧；其中272017步在未来10点中
也尚未观察到这条新计划的自由帧。此统计严格限定为“自己的当前区间”，不代表
计划在后续区间从未被消费，也不代表未来帧对Transformer输出没有作用。

因此现行R_k是合法的真实决策区间奖励，但其即时部分主要反映此前参考，新的动作
通过前瞻和后续真实执行产生影响，需要延迟信用。GAE已包含未来项；消费滞后不是
奖励写错的直接证据。本次不搬移原奖励、不删未立即消费的概率坐标、不增加重复
Root/Yaw/Joint惩罚。完整MC误差和消费时序必须分别核验。

新三窗口的紧凑账本进一步核验了1117400个计奖控制步、2103个物理episode范围，
全部范围连续、前缀来源完整，无缺失compact记录，去重后控制数量与逐记录数量相同。
本次实测新自由帧首次进入未来前瞻为生成后0.38秒，首次成为当前中心为0.58秒；
所以0.5秒的决策区间不会等到本次自由帧成为中心，但最后部分控制已可观察前瞻。
4015个计划的实际中心消费跨越了采集窗口边界。38212个具有完整可观测2秒范围的
计划，各有15个原始自由帧实际成为当前中心；该数量不能解释为其他帧没有影响。

进一步定位：价值校准覆盖和采样分布
--------------------------------

按原真实MC数据重载旧/新Critic独立前向，完整复现新验证MSE=5.1005946871，
不是仅凭训练器摘要推断。新Critic在MC训练数据上的MSE=0.3312，独立验证MSE=5.1006；
验证接管头2秒MSE=7.5626、偏差-2.2303，仍有局部低估，不能宣布优势问题完全消失。

MC监督的状态分布与20秒PPO实际采样有明显差异：

=====================  ============  =================
状态阶段               MC训练占比    三窗口PPO决策占比
=====================  ============  =================
首次GENMO生成          1.5620%       4.6831%
接管0～2秒             6.2480%       18.5944%
接管2～20秒            41.3928%      81.4056%
接管20秒以后           52.3593%      0
=====================  ============  =================

完整轨迹是获得MC真值的必要来源，但按全部状态均匀拟合时，过半监督落在正式采集
不会以当前决策访问的20秒以后；首次与早期接管状态在实际训练中的占比约高3倍。
这不意味着应删除尾部轨迹：20秒真实末态仍需要其后续完整回报和正确bootstrap。

本次MC拟合覆盖96个音乐group，三窗口实际采到366个，33803/44906条记录所在
group没有进入本次MC拟合。标准化优势最高的三条来自FineDance157/080/156，
三者group均未进入本次MC拟合或独立验证。例如157首次生成时V=-0.3875、下一状态
V=6.2834，当前冻结GAE优势17.9950，其中奖励项10.5417、价值项7.4533。
因此校准总体指标较好不能替代这些实际音乐/起点的价值核验；“未进入MC拟合”
不等于Stage1未学过，也不意味着所有未覆盖group都估错。覆盖关联不是严格因果证明。

下一步具体方向是保留完整轨迹计算MC，补齐实际训练音乐和接管状态的校准覆盖，
按正式PPO决策与20秒bootstrap查询分布安排Critic拟合/独立误差统计。优先复核
157/080/156等局部低估，不以更强教师约束、压低LR或裁剪优势掩盖学习信号问题。
本批没有自动加入这些新的训练采样规则，避免把本次明确要求的基线和后续消融混用。

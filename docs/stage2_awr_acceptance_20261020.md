# GENMO–GMT Stage2 AWR：2026-10-20 实现与有限验收

本文汇总独立 AWR 分支的实现、Server-2 的 64 集小型闭环、512 集首轮对照及后验检查。
所有物理结果均来自冻结 GMT 驱动的 Isaac PhysX 仿真，不是实机结果。
原始数值、模型身份、失败与启动回执保存在正文链接的 JSON 及服务器运行目录中。

**交付结论：五阶段系统已完成真实闭环和八卡计算验收；512 首轮减少了验证中的物理失败，
但完整任务回报的学习收益尚未充分证实。`best_saved` 继续保留原始 Stage1。**
没有启动第二宏迭代、后续四轮或 2000／500 规模训练。

## 4. Actor 与 Stage1 BC 实际更新

A 为冻结 s595000，B/C 分别从 s595000 独立初始化；B 的 Replay 权重全为 1，
C 使用上述固定权重。两组共用同一快照、有效样本、顺序、训练噪声安排、BC 数据流和优化预算。
断点组件核验还逐元素比较了最终八 rank BC 随机流。

每条样本归一化 qpos30，重新抽取扩散 t 与高斯噪声，保留条件和已知前缀重写。
只在有效未知坐标先求每样本 MSE，再加权：

```text
sample_loss_i = sum(mask_i * (predicted_x0_i - target_x0_i)**2) / max(sum(mask_i), 1)
L_total = mean_i(weight_i * sample_loss_i) + lambda_BC * L_Stage1
```

Replay Contact 输出仅诊断；Contact Head 的直接监督来自 BC 真标签。
八卡按实际全局样本数分别归一化 AWR 与 BC，处理空 rank/尾批，完整归约后裁剪。
全部原可训练 Actor 模块更新，没有保留 15+4+1 的采样步冻结。

本轮 AdamW LR=1e-5、weight decay=0.01、warmup=100 步、余弦最低比例 0.1、
clip=1；全局 AWR/BC Batch=256/128，每卡 microbatch=8/4。

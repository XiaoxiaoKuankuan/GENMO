# AWR为什么没有提高物理表现：2026-10-21冻结实验诊断

本报告回答“为什么AWR没有改善”，区分真实观测、机制解释和仍需消融的假设。
分析对象是已经正常结束的`group_credit64_20261021_01`，不是旧formal5的重启。
本轮仅读取原Replay、标签和模型，执行梯度与生成诊断，新增优化步和PhysX控制步均为0。
没有加教师约束、恢复自蒸馏门禁、修改奖励或启动后续训练。

**结论：目前证据最强的解释是，共同的扩散回归更新造成明显动作漂移，而物理优势信号
不足以把更新方向引向更容易跟踪的动作。** 高噪声重建改善和低噪声精修退化同时发生；
B/C更新方向高度相近。Critic在失败音乐上的误差、有效候选覆盖过少、参考暴露与动作
自由部分的区别、长歌曲占据更多训练份额共同削弱了强化信号。不能把全部问题归因于
CFG这个单一开关，也不能由这次负结果断言所有扩散AWR都无效。

## 3. 优先级最高：无权重回归有很强的共同更新方向

在原Stage1、同Replay Batch、同扩散时间与噪声下，四个256样本Batch的加权/无权重
Replay梯度余弦为0.963、0.954、0.954、0.915。加权差值范数约为无权重梯度的
29%–45%，因此不是“权重完全没有作用”；但主要更新方向高度一致。

B/C最终参数增量余弦为0.95043；固定16个音乐组条件和相同新生成种子，B/C相对A的
自由关节输出RMS变化分别为0.14094/0.13906rad（约8.08/7.97度）。左臂roll等关节出现
相似的偏移。普通自蒸馏这一路根本没有Critic权重，因此Critic错误不可能单独解释它的退化。

数学上，固定样本权重时：

    grad L_AWR = grad mean(loss_i) + mean((w_i - 1) grad loss_i)

全局mean(w)=1不会消掉第一项。这里第一项不是一个已经接近稳定点的微小背景，
它本身就较强。两组还共享原Stage1 BC，所以最终参数相似不能单独分离BC贡献；
但以上Replay梯度比较不含BC，说明共同方向确实存在于自生成样本去噪回归中。

不能把(w−1)直接拿来作为负MSE权重“修复”：负二次损失可能无下界，且缺少与实际
策略分布相匹配的推导。需要修正/验证目标本身，不能把一个统计分解当成新算法。

## 4. CFG公式已经一致，但采样和回归的统计目标仍不同

当前代码采样和Replay训练均使用`x_guided=2.5*x_cond−1.5*x_uncond`，不是旧版
“用单分支拟合CFG终点，再在采样时放大一次”的实现。这个旧问题已经修复，不能
再次把新实验的全部退化归给同一个旧错误。

但“自己生成终点→丢弃采样噪声对应关系→重新加独立噪声→回归终点”是在优化新的
去噪统计目标，不是逐步重放原生成映射。DDIM20+CFG给出的采样分布、前向再加噪后的
分布以及uniform-t的x0 MSE，并不自动满足“原模型就是自身回归最优解”的条件。
有限数据/随机梯度下，合理自蒸馏也不要求每个Batch梯度为0或同seed逐坐标恒等；
本次需要解释的是共同的、明显降低物理质量的漂移。

四来源各8条真实Replay样本，共32条固定探针，使用相同噪声，guided qpos归一化MSE：

| 扩散时间 | A | B | C |
|---|---:|---:|---:|
| 0，近干净动作 | 0.00158 | 0.00706 | 0.00696 |
| 100 | 0.00358 | 0.00752 | 0.00750 |
| 300 | 0.03716 | 0.01356 | 0.01389 |
| 600 | 0.14561 | 0.03382 | 0.03599 |
| 900 | 0.70472 | 0.10635 | 0.11047 |
| 999，高噪声 | 1.31735 | 0.14886 | 0.18447 |

模型在高噪声“猜原动作”上明显变好，低噪声精修却退化；t=0真实关节RMSE从0.01394rad
升到B/C约0.03231/0.03156rad。原模型t=999的单条件分支MSE为0.08475，而guided输出
为1.31735。这说明不能把原guided预测当成再加噪训练分布下已最优的重建器。
**损失大小本身不能证明梯度贡献大小或方向冲突**，因此另做同一32样本、同一噪声的
固定时间梯度测量，不进行优化器更新，结果如下：

| 扩散时间 | 原始Replay梯度范数 | 相对t=0倍数 | 与t=0梯度余弦 |
|---|---:|---:|---:|
| 0 | 0.39275 | 1.00 | 1.00000 |
| 100 | 0.70775 | 1.80 | +0.22149 |
| 300 | 4.14511 | 10.55 | −0.18768 |
| 600 | 11.24292 | 28.63 | −0.10148 |
| 900 | 62.92728 | 160.22 | −0.04780 |
| 999 | 112.22628 | 285.74 | −0.00469 |

这些是裁剪/Adam之前、不含BC的原始梯度。中噪声部分与低噪声精修存在负内积，
最高噪声主要是很大的近正交更新，不能称为“完全反向”。在这一探针上，uniform-t
均匀采样不等于各噪声档对参数的影响均衡。全局clip只能缩放已混合梯度，不能恢复
它内部各时间档的比例；Adam预条件和95步后的变化仍需单独考虑，不能用初始梯度
数值直接推算物理损失百分比。它与高噪声MSE改善、低噪声精修退化及B/C共同漂移
相互吻合，构成目前最具体的机制证据；尚不是改动单一因素后的因果恢复实验。

相关理论边界：扩散加权回归使用的去噪损失是似然的近似目标；CFG训练与CFG采样保持
一致能解决特定分支失配，但不提供所有有限步采样/再训练都保持分布的保证。
这与[Black等的§4.2和附录E.1](https://arxiv.org/html/2305.13301v4#S4.SS2)一致；
该论文不是本项目根因的实验替代，也不构成把项目切回PPO的建议。

## 5. Critic跨折正确，不等于足以分辨动作质量

每折实际只用4首不同音乐训练：每来源1首，每首4种子，合计16Episode；另4首用于
内部验证。64Episode不能理解成64种独立音乐状态分布。两折MC+FVI都改善整体MSE，
但所选Critic的内部验证细分如下：

| 拟合折 | 整体EV | FineDance/失败Episode EV | 失败Episode MAE | 失败Episode偏差 |
|---|---:|---:|---:|---:|
| A | 0.41993 | 0.01580 | 22.56701 | +0.13792 |
| B | 0.41734 | −0.01342 | 24.01076 | +22.47392 |

失败音乐的EV接近0或为负，意味着仍不能解释这部分回报的起伏。B折整体偏差只有
−0.49097，却是FineDance高估与其他来源低估相互抵消。交叉拟合防止直接训练泄漏，
不能保证一个只见过4首音乐的基线准确。这是权重噪声/来源时间偏差的具体风险；
尚未通过替换为真实同状态回报的Actor对照量化它造成了多少奖励损失。

## 6. “让模型比较好坏候选”目前只有极少训练覆盖

4组×4候选完整完成；AIOZ和FineDance两组初态逐字段差为0，AIST/Mine两组实际状态
超严格容差，正确回退。只有8条首次动作有合法Group Advantage，占4757条的0.1682%，
最终权重质量占比约0.1622%。配置中的25%是候选Episode比例，不是有效组内动作比例。
后续每0.5秒决策不能冒充相同物理状态比较，因此组内信号被大量普通样本稀释。

另一个具体问题是hybrid可能逆转候选的短窗口排序。FineDance候选0/3的2秒共同回报
为4.893785/4.895729，候选3更高，但最终权重为0.884832/0.539365。
纯grouped模式排序正确，混合的MC/credit改变了排序；不是Group Advantage减均值公式
算错。当前配置没有保证“同条件更高回报候选优先”。是否应对这些有效首动作使用独立
的组内目标/预算，需要受控对照，而不是无依据提高指数权重。

## 7. Reference credit已对齐消费，但仍是暴露近似

新增诊断严格按21点参考窗口中每个计划的实际份额统计：首次成为当前参考比生成
决策晚0.52秒。总加权暴露在生成所在区间/后一区间/后两区间约为9.08%/88.94%/1.98%。
N=4不代表四个区间对该动作都提供同等局部监督；绝大部分直接暴露在下一决策区间。
仍有bootstrap Value影响，不能把暴露为0误解为未来完全没有影响。

8.05%的计划加权暴露对应它保存的已知关节前缀，而不是该次新生成的自由关节。
plan_id所有权和“本次Actor可改变什么”不是完全相同的集合。此统计不改变原奖励，
也没有在Replay重复写奖励；它说明c_ij不能直接被称为严格因果信用。

每条目标有43个未知关节帧，但本计划成为当前参考的时间通常只有0.5秒，约15帧；
完整窗口监督还包括后来被替换的部分。完整60帧回归是已批准的初版设计，不是数据
丢失bug，但把一条局部好坏标签乘到整个自由窗口会稀释归因。是否对消费/前瞻/替换
部分分别加权，应保留完整窗口基线做消融，不能直接删除未来帧。

**旧质量统计口径更正：** `advantages.py`原报告中的部分Tracking统计取决策所在
interval，而非该plan实际消费区间。新诊断只读重算真正暴露时段，原标签不重写：

| 来源 | 权重与真实暴露Joint误差相关 | 权重与剩余音乐秒数相关 |
|---|---:|---:|
| AIOZ | −0.02609 | +0.68897 |
| AIST | −0.41729 | −0.09468 |
| FineDance | −0.06792 | +0.42062 |
| Mine | −0.02507 | +0.88918 |

三个来源中Joint相关接近0，而部分来源的音乐剩余时间相关很强。Root误差有较明显的
负相关，不能说权重完全不含物理质量信息；也不能把时间相关单独当成标签错误。
这些是同来源相关诊断，仍有歌曲难度、阶段和失败风险混杂；严格候选对照优先。

## 9. 下一步应验证目标和信号，不能只延长训练

优先顺序如下，均为尚未执行的受控实验建议，不恢复训练：

1. **隔离共同回归漂移。** 固定同Replay/噪声，比较不同扩散时间、采样/回归定义和
   qpos分模块的梯度及生成变化；验证新目标为什么不应在没有质量选择时系统性破坏
   生成分布。不要求模型恒等、不加教师锁定，也不以极低LR掩盖目标问题。
   仅修改一个因素，保留当前guided训练为负结果基线。
2. **提高真实同状态比较的有效覆盖。** 先定位AIST/Mine预热状态差异，在实际初态
   一致且组完整的样本上比较纯grouped与hybrid，直接检查高回报动作是否得到更强更新。
   预算按有效首动作计，不用候选Episode占比冒充监督覆盖；不放宽严格状态校验。
3. **检验局部信用。** 区分生成自由坐标、复制前缀和真实消费/前瞻/替换区域，保留
   当前账本与MC基线，分析它们与Root/Body/Joint/Yaw误差的关系。先做标签与目标对齐
   对照，不再重复增加已有Tracking惩罚。
4. **检验Critic和来源分布。** 增加每折不同音乐组/失败状态的覆盖，按来源/失败类型
   报告价值偏差和候选排序；对齐来源训练目标和评价权重。不能因整体EV增加就判定
   所有音乐优势可信，也不应直接把beta调小来放大不可靠标签。

这些不是“自蒸馏必须通过才允许AWR”的流程门禁。是为区分机制而设计的对照，之后
仍以真实训练音乐奖励判断收益。现有数据尚不能给各原因精确分摊损失百分比，不能
声称改完某一个开关就会有效。

本轮新增工具为`tools/diagnose_stage2_awr_learning.py`，只读核对Replay/checkpoint/SHA，
计算梯度、固定条件生成和真实消费统计；原训练配置、原模型、Critic/标签及运行state
没有改变。相关代码位置：`actor.py:305`、`awr/trainer.py:110`、`awr/losses.py`、
`awr/advantages.py:180`、`awr/reference_credit.py:84`。

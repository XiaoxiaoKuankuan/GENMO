# 文本分支测试范围

默认 `python -B -m pytest` 按根目录 `pytest.ini` 收集当前 BUMI 文本、数据、机器人表示、
导出、网页和公共组件测试。输出必须通过 `--basetemp` 指向本次任务的独立 `/tmp` 目录，
运行结束删除该目录；配置已关闭 pytest 缓存。GPU/MJCF 外部环境测试按各自条件执行。

音乐、人体 SMPL、视频、旧资产和旧数据构建测试源码原位保留，默认不收集。这些文件
对应的实现已由相应功能分支维护，不能在文本分支执行 `pytest tests/` 并声称是当前测试集。
需要历史复现时使用对应分支或整理前提交 `23fd802`；不要把归档测试恢复到生产入口。

现行测试所需的人工源数据夹具位于 `bumi/text_source_fixtures.py`，不依赖历史人体测试模块。
默认测试集覆盖已有 full300 checkpoint 契约兼容，当前正式训练仍为四库 crop120。
